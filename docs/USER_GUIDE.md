## 1. 시작하기

### 접속 및 로그인

1. PC에서 **Chrome 브라우저**를 엽니다
2. 주소창에 배포된 URL을 입력합니다
3. 로그인 화면이 나옵니다:
   - **이메일**: 발급받은 이메일 주소 입력
   - **비밀번호**: 발급받은 비밀번호 입력
   - **[로그인]** 버튼 클릭
4. 로그인 성공하면 **대시보드** 화면이 나옵니다

> 계정은 관리자가 별도로 생성해드립니다. 비밀번호를 잊으셨으면 관리자에게 문의하세요.

### 화면 구성

화면 **왼쪽에 사이드바** 메뉴가 있습니다. 여기서 원하는 페이지로 이동합니다.

| 메뉴 | 위치 | 무슨 페이지? |
|------|------|-------------|
| **대시보드** | 맨 위 | 오늘 할 일 한눈에 보기, 빠른 시작 버튼 |
| **발주서** | 주문 관리 | 주문 엑셀 올리고 → 공급처별 발주서 만들기 |
| **운송장** | 주문 관리 | 운송장 올리고 → 쿠팡/토스에 올릴 파일 만들기 |
| **매핑관리** | 설정 | 공급처, 품목, 상품명, 택배사, 과일사전 관리 |
| **운송장 양식** | 설정 | 쿠팡/토스 운송장 양식 파일 관리 |
| **사용 가이드** | 맨 아래 | 이 가이드 (앱 안에서도 볼 수 있음) |

### 다크모드 / 라이트모드

사이드바 맨 아래에 **테마 전환 버튼**이 있습니다. 클릭하면 밝은 화면 / 어두운 화면을 바꿀 수 있습니다.

## 2. 매일 운영 순서 요약

매일 아침 이 순서대로 진행하면 됩니다.

```
① 로그인 → 대시보드에서 [새 발주 작업 시작] 클릭
② 쿠팡 주문 엑셀 업로드
③ 토스 주문 엑셀 업로드
④ 품목 검토 — 오늘 주요 품목의 공급처를 미리 선택 (안 하고 건너뛰어도 됨)
⑤ 공급처 배정 확인 — "미분류"가 있으면 공급처 지정
⑥ 공급처별 발주서 다운로드 → 카톡이나 이메일로 공급처에 전달
⑦ [발주 완료 처리] 클릭
⑧ (공급처에서 운송장 보내주면) 운송장 엑셀 업로드
⑨ 매칭 결과 확인 — 빨간색 "미매칭"이 있으면 수동으로 연결
⑩ 쿠팡/토스 운송장 파일 다운로드 → 각 플랫폼 셀러 페이지에 업로드
⑪ [운송장 처리 완료] 클릭
```

## 3. 발주서 — 단계별 상세

### 3-1. 작업건 만들기

**"작업건"이 뭔가요?**
하루에 한 번 만드는 "오늘의 발주 묶음"입니다. 오늘 올린 주문, 배정, 발주서, 운송장이 이 작업건 안에 묶입니다.

**만드는 방법:**
1. 사이드바에서 **발주서** 클릭
2. 파란색 **[새 발주 작업 시작]** 버튼 클릭
3. 작업건 이름을 입력합니다 (자동으로 "2026-05-14 오전 발주" 같이 채워져 있음)
4. **[만들기]** 클릭

> 이전에 만든 작업건을 이어서 하려면? 목록에서 해당 작업건을 클릭하면 됩니다.

### 3-2. 주문 엑셀 업로드

**여기서 할 일:** 쿠팡/토스 셀러 페이지에서 다운받은 주문 엑셀 파일을 시스템에 올립니다.

#### 쿠팡 주문 업로드

1. **"쿠팡 주문 엑셀"** 영역에 파일을 **마우스로 끌어다 놓거나**, 클릭해서 파일을 선택합니다
2. 파일이 자동으로 읽히고, 결과가 표시됩니다:
   - **정상 243건**: 잘 읽힌 주문 수
   - **오류 2건**: 필수 정보가 빠진 행 (행 번호랑 이유가 나옴)
   - **중복 0건**: 같은 매칭번호가 2번 나온 건
3. 오류 건은 무시해도 됩니다 (정상 건만 처리됨)

#### 토스 주문 업로드

쿠팡과 같은 방식으로 토스 파일도 올립니다.

#### 쿠팡 파일이 2개 이상일 때

쿠팡에서 주문 목록을 2개 파일로 나눠 다운받았을 때:

1. 첫 번째 파일을 업로드합니다
2. 두 번째 파일을 올리면 팝업이 뜹니다:
   - **"기존 주문에 추가"** → 기존 주문·공급처 배정·운송장을 유지하고 새 주문만 추가 (중복은 자동 제외). 파일이 여러 개면 추가할 기존 파일을 선택합니다.
   - **"별도 파일로 업로드"** → "쿠팡1", "쿠팡2"로 따로 관리됨. 나중에 운송장 다운로드할 때도 파일이 따로 나옴

#### 잘못 올렸을 때 (재업로드)

같은 플랫폼 파일을 다시 올리면:
- "기존 데이터를 삭제하고 새로 업로드합니다" 팝업이 뜸
- **[재업로드]** 클릭하면 이전 데이터가 지워지고 새 파일로 교체됨

#### 다 올렸으면

화면 아래의 **[품목 검토로 이동]** 버튼을 클릭합니다.

### 3-3. 품목 검토 (건너뛰어도 됨)

**여기서 할 일:** 오늘 주문된 주요 품목(사과, 참외, 귤 등)을 보고, 각 품목을 어느 공급처에 보낼지 미리 정합니다.

> 이 단계는 **선택 사항**입니다. 건너뛰면 기존에 등록된 매핑 기준으로 자동 배정됩니다.
> 매일 공급처가 바뀌는 품목이 있을 때 유용합니다.

#### 화면에 보이는 것

테이블에 오늘 주문된 품목이 **발주량 많은 순서**로 나열됩니다:

| 열 | 설명 | 예시 |
|----|------|------|
| **품목** | 주문에서 추출된 과일 이름 | 사과, 참외, 한라봉 |
| **건수** | 이 품목의 주문 건수 | 120건 |
| **수량** | 이 품목의 총 수량 (박스 등) | 360 |
| **공급처** | 드롭다운 — 여기서 공급처를 선택 | [A농장 ▾] |
| **기본 저장** | 체크박스 — 다음에도 이 공급처를 쓸지 | ☐ |

#### 공급처 드롭다운을 클릭하면

추천 공급처가 **맨 위에** 표시됩니다. 각 추천 옆에 이유가 나옵니다:

| 표시 | 의미 |
|------|------|
| 🔵 **기본** | 품목 매핑에 기본으로 등록된 공급처 |
| 🟢 **전날** | 어제 이 품목을 보냈던 공급처 |
| 🟡 **최다** | 최근 30일간 이 품목을 가장 많이 보낸 공급처 |
| 💰 **최저가** | 카탈로그 기준 가격이 가장 싼 공급처 |

추천 아래에 나머지 공급처 전체 목록이 나옵니다. 그리고 맨 아래에 **"자동 배정"** 옵션이 있습니다 — 이걸 선택하면 시스템이 알아서 배정합니다.

#### "기본 저장" 체크박스

공급처를 **변경했을 때만** 체크박스가 나타납니다.

- **체크하면** → 이 품목의 기본 공급처가 **영구적으로** 바뀝니다. 내일부터 이 품목은 항상 이 공급처로 배정됩니다.
- **체크 안 하면** → **오늘만** 이 공급처로 배정됩니다. 내일은 원래대로 돌아갑니다.

#### 다 선택했으면

- **[배정 시작]** 클릭 → 선택한 공급처가 반영되어 자동 배정이 시작됩니다
- **[건너뛰기]** 클릭 → 품목 검토를 안 하고 바로 배정 페이지로 넘어갑니다. 기존 매핑 기준으로 자동 배정됩니다.

> **품목 그룹핑은 어떻게 되나요?**
> 시스템이 상품명에서 과일 이름을 자동으로 뽑습니다.
> - "고당도 사과 3kg", "사과 5kg" → 둘 다 "사과"로 묶임
> - 과일 사전에 동의어를 등록하면 "부사"도 "사과"로 묶을 수 있습니다 (→ 9장 참고)
> - 과일 사전이 없어도 사과, 참외, 수박 등 40여 종은 자동 인식됩니다

### 3-4. 공급처 배정

**여기서 할 일:** 시스템이 자동 배정한 결과를 확인하고, 틀린 것만 수정합니다.

#### 화면에 보이는 것

주문이 **공급처별 그룹**으로 표시됩니다. 예를 들면:

```
▼ A농장 (120건 · 360개)
  사과 3kg  수취인홍길동  서울시...  [A농장 ▾]
  사과 5kg  수취인김철수  부산시...  [A농장 ▾]
  ...

▼ B농장 (95건 · 285개)
  참외 5kg  수취인이영희  대구시...  [B농장 ▾]
  ...

▼ 미분류 (3건 · 9개)     ← 자동 배정 못 한 주문
  블루베리 1kg  수취인박지민  ...  [공급처 선택 ▾]
```

#### "미분류" 처리하기

**미분류**는 시스템이 어느 공급처로 보낼지 몰라서 배정하지 못한 주문입니다.

1. 미분류 그룹의 주문 행에서 **[공급처 선택]** 드롭다운을 클릭
2. 공급처를 선택합니다
3. 선택하면:
   - 이 주문이 해당 공급처로 배정됩니다
   - **동시에 품목 매핑에 자동 등록됩니다** → 다음에 같은 상품이 오면 자동 배정됩니다

#### 이미 배정된 공급처 바꾸기

1. 바꾸고 싶은 주문 행의 **공급처 칩** (예: "A농장")을 클릭
2. 새 공급처를 선택합니다
3. 선택지가 나옵니다:
   - **"오늘만 변경"** → 이번 작업건에서만 적용. 다음에는 원래대로.
   - **"기본 변경"** → 앞으로 이 상품은 항상 새 공급처로 배정됩니다.

#### 한 품목을 여러 공급처에 나누기 (수량 분배)

예: 사과 100건 중 60건은 A농장, 40건은 B농장으로 보내고 싶을 때

1. 공급처 그룹 헤더의 **[분배]** 버튼 클릭
2. 팝업에서 공급처별 수량을 입력합니다
3. **[확인]** 클릭하면 주문이 자동으로 나뉩니다

> 주의: 1건의 주문을 쪼개는 건 안 됩니다. "사과 3개 주문"을 A 2개 + B 1개로 나누는 건 불가.
> "주문 100건" 중 60건/40건으로 나누는 것만 가능합니다.

#### 다 확인했으면

**[발주서 다운로드로 이동]** 버튼을 클릭합니다.

### 3-5. 발주서 다운로드

**여기서 할 일:** 공급처별 발주서 엑셀 파일을 다운로드해서 공급처에 보냅니다.

#### 화면에 보이는 것

공급처별로 카드가 나옵니다:

```
┌──────────────────────────────┐
│ A농장                        │
│ 주문 120건 · 수량 360개      │
│            [다운로드]  🗑️    │
└──────────────────────────────┘

┌──────────────────────────────┐
│ B농장                        │
│ 주문 95건 · 수량 285개       │
│            [다운로드]  🗑️    │
└──────────────────────────────┘
```

#### 다운로드 방법

- **개별 다운로드**: 각 카드의 **[다운로드]** 클릭 → 해당 공급처 발주서 엑셀 파일 1개 다운로드
- **전체 다운로드**: 상단의 **[전체 다운로드]** 클릭 → 모든 공급처 발주서가 한꺼번에 다운로드

> **"양식 미등록"이 표시되면?**
> 해당 공급처의 발주서 양식이 등록되지 않은 것입니다.
> → 매핑관리 → 공급처 관리 → 해당 공급처 클릭 → 발주서 양식 등록 (10장 참고)

#### 발주서를 공급처에 보내기

다운로드한 엑셀 파일을 카카오톡, 이메일 등으로 공급처에 보냅니다.

### 3-6. 발주 완료 처리

모든 발주서를 보냈으면:

1. **[발주 완료 처리]** 버튼 클릭
2. "발주를 완료합니까?" 팝업에서 **[확인]** 클릭
3. 작업건 상태가 **"발주완료"** 로 바뀝니다
4. 이제 운송장을 받으면 운송장 처리를 진행할 수 있습니다

### 3-7. 발주 되돌리기

"발주완료 했는데 배정을 수정해야 할 때":

1. 발주서 다운로드 페이지 상단의 초록 배너에서 **[발주 되돌리기]** 클릭
2. 작업건이 **"진행중"** 상태로 돌아갑니다
3. 배정을 수정하고 다시 [발주 완료 처리]를 할 수 있습니다
4. 기존 배정 데이터는 그대로 유지됩니다 (처음부터 다시 할 필요 없음)

### 3-8. 공급처별 배정 삭제

특정 공급처의 배정만 취소하고 싶을 때:

1. 발주서 다운로드 페이지에서 해당 공급처 카드의 🗑️ 아이콘 클릭
2. 해당 공급처에 배정된 주문이 **"미분류"** 상태로 돌아감
3. 배정 페이지로 가서 다시 배정할 수 있습니다
4. **"진행중"** 상태에서만 가능합니다 (발주완료 후에는 먼저 되돌리기를 해야 함)

### 3-9. 작업건 삭제

잘못 만든 작업건을 삭제할 때:

1. 발주서 작업건 목록에서 해당 작업건 오른쪽의 🗑️ 아이콘 클릭
2. "삭제합니까?" 팝업에서 **[삭제]** 클릭
3. 이 작업건에 속한 **모든 데이터(주문, 배정, 운송장)가 삭제**됩니다
4. **되돌릴 수 없습니다** — 신중하게 클릭하세요

## 4. 운송장 처리 — 단계별 상세

운송장 처리에는 **2가지 방식**이 있습니다:

| 방식 | 언제 쓰나요? |
|------|-------------|
| **일반 운송장** | 매칭 결과를 상세히 보고 싶을 때, 미매칭을 수동으로 처리해야 할 때 |
| **간편 운송장** | 빠르게 처리하고 싶을 때. 작업건 없이 바로 파일만 넣으면 됨 |

### 4-1. 일반 운송장

#### 운송장 업로드

1. 사이드바에서 **운송장** 클릭
2. 작업건 목록에서 처리할 작업건 클릭
3. 운송장 업로드 화면이 나옵니다
4. **공급처를 먼저 선택합니다** (드롭다운에서 선택)
5. 운송장 엑셀 파일을 **드래그하거나 클릭해서 업로드**
6. 파싱 결과가 표시됩니다 (정상/오류 건수)
7. 다른 공급처의 운송장도 같은 방식으로 업로드합니다

> **잘못 올린 운송장 삭제**: 업로드된 운송장 옆의 🗑️ 아이콘 클릭 → 확인 → 삭제됨

#### 매칭 결과 확인

**매칭 결과** 탭을 클릭하면 운송장과 주문의 매칭 현황이 나옵니다.

**상단 통계 카드:**
| 카드 | 의미 |
|------|------|
| **전체 N건** | 업로드된 총 운송장 수 |
| **매칭 N건** | 매칭번호가 일치해서 자동 연결된 건 |
| **미매칭 N건** | 일치하는 주문을 못 찾은 건 |
| **중복 N건** | 같은 주문에 운송장이 2개 이상인 건 |

**공급처별 매칭 진행률:**
통계 아래에 공급처별 칩이 표시됩니다:
- ✅ **초록 체크 + 공급처명** → 이 공급처 운송장 100% 매칭 완료
- **원형 프로그레스 + "매칭 58/60"** → 아직 진행 중 (60건 중 58건 매칭)

**테이블:**
각 운송장 행에 매칭 상태가 색상으로 표시됩니다:
- **초록 "매칭됨"** → 정상
- **빨간 "미매칭"** → 수동 처리 필요
- **주황 "중복"** → 확인 필요

> **공급처 필터**: 테이블 위의 공급처 드롭다운으로 특정 공급처만 필터링해서 볼 수 있습니다.

#### 수동 매칭 (미매칭 처리하기)

미매칭이 있으면 직접 주문을 연결해야 합니다:

1. 빨간색 "미매칭" 행의 **[수동 매칭]** 클릭
2. 주문 목록 팝업이 뜹니다
3. 올바른 주문을 찾아서 클릭합니다
4. 매칭 완료 → 상태가 "매칭됨"으로 바뀝니다

> 주로 공급처가 운송장에 매칭번호를 잘못 적었을 때 미매칭이 발생합니다.

#### 플랫폼 파일 다운로드

**플랫폼 파일 다운로드** 탭을 클릭합니다.

쿠팡과 토스 카드가 각각 표시됩니다:

```
┌──────────────────────────────────┐
│ 쿠팡                              │
│                                    │
│ 쿠팡1 (120건)         [다운로드]   │
│ 쿠팡2 (80건)          [다운로드]   │
│                                    │
│              [전체 다운로드]        │
└──────────────────────────────────┘
```

**다운로드 방법:**
- **개별**: 각 라벨(쿠팡1, 쿠팡2 등) 옆의 **[다운로드]** 클릭
- **전체**: **[전체 다운로드]** 클릭 → 라벨별로 개별 파일이 **각각** 다운로드됨 (합쳐진 파일이 아님!)

> **미매칭 경고**: 미매칭 건이 있으면 노란색 경고 배너가 뜹니다. 미매칭 건은 운송장 파일에 포함되지 않으니 매칭을 먼저 처리하세요.

다운로드한 파일을 **쿠팡 셀러 / 토스 셀러 페이지**에서 업로드합니다.

#### 운송장 처리 완료

모든 운송장 파일을 다운로드하고 플랫폼에 업로드했으면:

1. **[운송장 처리 완료]** 클릭
2. 작업건 상태가 **"완료"** 로 바뀝니다
3. 대시보드에서 완료된 작업건으로 표시됩니다

### 4-2. 간편 운송장

작업건 없이 빠르게 운송장을 처리하는 모드입니다.

**시작 방법:**
1. 사이드바에서 **운송장** 클릭
2. 화면 오른쪽 위의 **[간편 운송장]** 버튼 클릭

**Step 1 — 주문 업로드:**
- 쿠팡/토스 주문 엑셀 파일을 업로드합니다
- 파일을 올리면 자동으로 읽혀서 주문 목록이 표시됩니다

**Step 2 — 운송장 업로드:**
- 공급처를 선택하고 운송장 엑셀을 업로드합니다
- 올리는 즉시 주문과 자동 매칭됩니다
- 공급처별 매칭 결과를 확인할 수 있습니다 (매칭/미매칭 탭)
- 여러 공급처의 운송장을 순서대로 올릴 수 있습니다

**Step 3 — 다운로드:**
- 쿠팡/토스 플랫폼 파일을 다운로드합니다

> **주의**: 간편 운송장은 **DB에 저장되지 않습니다**. 페이지를 벗어나면 데이터가 사라집니다.
> 반드시 파일을 다운로드한 후 페이지를 나가세요.

## 5. 매핑관리 — 공급처 관리

사이드바 **매핑관리** → 왼쪽 탭에서 **공급처 관리** 클릭

**"공급처"란?** 과일을 납품받는 거래처(농장, 도매 등)입니다.

### 공급처 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **공급처명** | 거래처 이름 | 필수 | `A농장` |
| **연락처** | 전화번호나 담당자 | 선택 | `010-1234-5678 김사장님` |
| **메모** | 참고할 내용 | 선택 | `사과 전문, 화요일 배송불가` |

3. **[추가]** 클릭 → 목록에 추가됩니다

### 공급처 수정하기

1. 수정할 공급처 행의 **[수정]** (연필 아이콘) 클릭
2. 내용 수정 후 **[저장]** 클릭

### 공급처 상세 페이지

공급처 행을 **클릭**하면 상세 페이지로 이동합니다. 여기서:

- **기본 정보 수정**: 이름, 연락처, 메모
- **발주서 양식 등록**: 이 공급처에 보낼 발주서 엑셀 양식 설정 (→ 10장 참고)
- **상품 카탈로그**: 이 공급처의 상품 목록을 업로드할 수 있음

> **상품 카탈로그를 올리면 뭐가 좋나요?**
> - 자동 배정 시 **가격, 재고** 정보를 참고해서 더 똑똑하게 배정합니다
> - 배정 페이지에서 각 주문 옆에 **공급처 가격**이 표시됩니다
> - 품목 검토에서 **최저가 추천**이 가능해집니다

### 공급처 비활성화 / 복원 / 삭제

| 동작 | 어떻게? | 뭐가 되나요? |
|------|---------|-------------|
| **비활성화** | 공급처 행의 토글 버튼 OFF | 새 배정에서 제외됨. 기존 데이터는 유지. |
| **활성화 복원** | 비활성 목록에서 토글 버튼 ON | 다시 배정 대상에 포함됨. |
| **완전삭제** | 비활성 목록에서 🗑️ 클릭 | DB에서 완전히 지워짐. 되돌릴 수 없음. 이 공급처로 배정/운송장 처리한 이력이 있으면 삭제 불가. |

> 비활성화된 공급처를 보려면 목록 상단에 "비활성" 섹션이 아래에 표시됩니다.

## 6. 매핑관리 — 품목 매핑

사이드바 **매핑관리** → 왼쪽 탭에서 **품목 매핑** 클릭

**"품목 매핑"이 뭔가요?**
"이 상품은 이 공급처로 보내라"는 규칙입니다. 예를 들어:

```
"산지직송 성주 꿀참외" (쿠팡) → A농장
"참외 5kg 특상품"       (토스) → A농장
"프리미엄 사과 세트"     (공통) → B농장
```

이 규칙이 있으면, 주문이 들어올 때 시스템이 자동으로 맞는 공급처에 배정합니다.

### 품목 매핑이 만들어지는 2가지 방법

**방법 1 — 자동 등록 (가장 편함):**
- 공급처 배정 페이지에서 "미분류" 주문에 공급처를 지정하면
- 그 상품명+공급처가 **자동으로 품목 매핑에 등록**됩니다
- 다음에 같은 상품이 오면 자동 배정됩니다

**방법 2 — 수동 등록:**
- 품목 매핑 페이지에서 직접 추가합니다 (아래 참고)

### 수동으로 품목 매핑 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **플랫폼** | 쿠팡/토스/공통 중 선택. "공통"이면 쿠팡+토스 둘 다 적용 | 필수 | `공통` |
| **상품명** | 플랫폼에서 들어오는 등록상품명. **정확히** 적어야 매칭됨 | 필수 | `산지직송 성주 꿀참외` |
| **옵션명** | 플랫폼 옵션명. 비워두면 모든 옵션에 적용됨 | 선택 | `1박스 특가혼합과 5kg` |
| **공급처** | 이 상품을 보낼 공급처 선택 | 필수 | `A농장` |
| **우선순위** | 숫자 (0~999). 같은 상품에 여러 매핑이 있으면 높은 숫자가 우선 | 선택 | `0` |
| **기본** | 체크하면 이 공급처가 기본 배정 대상 | 선택 | ☑ |

3. **[저장]** 클릭

> **"상품명"은 정확히 뭘 넣어야 하나요?**
> 쿠팡이면 "등록상품명" (쿠팡 셀러에서 보이는 상품명), 토스면 "상품명"입니다.
> 주문 업로드 후 배정 페이지에서 보이는 상품명을 그대로 복사해서 넣으면 됩니다.

> **"옵션명"을 비워두면?**
> 옵션과 상관없이 **상품명만** 일치하면 매핑됩니다.
> 예: 상품명 "사과"만 넣고 옵션을 비우면 → "사과 3kg", "사과 5kg" 모두 매핑됩니다.

> **같은 상품에 여러 공급처를 넣을 수 있나요?**
> 네, 가능합니다. "기본" 체크된 공급처가 자동 배정 시 선택됩니다.
> 나머지는 수동으로 변경할 때 후보로 나옵니다.

### 품목 매핑 수정/삭제

- **수정**: 행의 연필 아이콘 클릭 → 수정 → [저장]
- **삭제**: 행의 🗑️ 아이콘 클릭 → 확인 → 삭제됨

### 일괄 등록

상단의 **[일괄 등록]** 클릭하면, 현재 작업건에서 아직 매핑되지 않은 품목을 한꺼번에 등록할 수 있습니다.

## 7. 매핑관리 — 상품명 변환

사이드바 **매핑관리** → 왼쪽 탭에서 **상품명 변환** 클릭

**"상품명 변환"이 뭔가요?**
플랫폼에 있는 상품명을 공급처가 알아보는 이름으로 바꿔주는 규칙입니다.

예시:
| 플랫폼 상품명 | → | 공급처 발주서에 표시되는 이름 |
|-------------|---|---------------------------|
| 프리미엄 산지직송 사과 세트 3kg | → | 사과 3kg |
| [특가] 성주 꿀참외 혼합과 5kg | → | 참외 혼합 5kg |

**품목 매핑과 뭐가 다른가요?**
- **품목 매핑**: "이 상품 → 이 공급처로 보내라" (배정 규칙)
- **상품명 변환**: "이 상품명 → 발주서에 이 이름으로 써라" (이름 변환 규칙)

### 상품명 변환 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **플랫폼** | 쿠팡/토스/공통 중 선택 | 필수 | `공통` |
| **플랫폼 상품명** | 플랫폼에서 들어오는 상품명 (정확히) | 필수 | `산지직송 성주 꿀참외` |
| **플랫폼 옵션명** | 플랫폼 옵션명 (비워두면 모든 옵션 적용) | 선택 | `1박스 특가혼합과 5kg` |
| **공급처** | 이 변환을 적용할 공급처 선택 | 필수 | `A농장` |
| **공급처 상품명** | 발주서에 적힐 이름 | 필수 | `정품 참외 중소과 5kg` |
| **공급처 상품코드** | 공급처 자체 상품 코드가 있으면 입력 | 선택 | `PIDY82D` |

3. **[저장]** 클릭

> **공급처 상품명 칸에 뭘 넣어야 하나요?**
> 공급처 발주서에 적어야 하는 상품 이름입니다. 공급처에서 "이 이름으로 보내주세요"라고 한 이름을 넣으면 됩니다.

### 자동 매칭 제안

공급처 상품 카탈로그가 등록되어 있으면, 시스템이 **"이 플랫폼 상품과 이 공급처 상품이 비슷한 것 같은데?"** 하고 자동으로 제안을 해줍니다.

- 상품명 변환 페이지 상단에 제안 카드가 표시됩니다
- 제안이 맞으면 **[적용]** 클릭
- 틀리면 무시하면 됩니다

> 공급처 상품명 입력칸에 글자를 타이핑하면 카탈로그에서 **자동완성**도 됩니다.

## 8. 매핑관리 — 택배사 매핑

사이드바 **매핑관리** → 왼쪽 탭에서 **택배사 매핑** 클릭

**"택배사 매핑"이 뭔가요?**
공급처가 운송장에 적는 택배사 이름을 쿠팡/토스가 인식하는 이름으로 변환하는 규칙입니다.

예시:
| 공급처가 적은 이름 | → 쿠팡에 올릴 이름 | → 토스에 올릴 이름 |
|------------------|------------------|------------------|
| CJ대한통운 | CJ대한통운 | CJ대한통운 |
| 한진택배 | 한진택배 | 한진택배 |
| 우체국 | 우체국택배 | 우체국택배 |
| 로젠 | 로젠택배 | 로젠택배 |

### 택배사 매핑 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **공급처** | 이 택배사명을 사용하는 공급처 | 필수 | `A농장` |
| **원본 택배사명** | 운송장에 적혀있는 택배사명 (정확히) | 필수 | `대한통운` |
| **쿠팡 택배사명** | 쿠팡에 업로드할 때 넣을 이름 | 필수 | `CJ대한통운` |
| **토스 택배사명** | 토스에 업로드할 때 넣을 이름 | 필수 | `CJ대한통운` |

3. **[저장]** 클릭

> **택배사 매핑이 없으면?**
> 공급처가 운송장에 적은 이름이 그대로 쿠팡/토스에 들어갑니다.
> 이름이 안 맞으면 플랫폼에서 오류가 날 수 있으니 등록해두는 게 좋습니다.

> **같은 공급처에서 택배사를 여러 개 쓰면?**
> 각 택배사별로 따로 등록하면 됩니다.
> 예: A농장이 CJ랑 한진을 둘 다 쓰면 → 2개 매핑 등록

## 9. 매핑관리 — 과일 사전

사이드바 **매핑관리** → 왼쪽 탭에서 **과일 사전** 클릭

**"과일 사전"이 뭔가요?**
시스템이 상품명에서 **과일 종류, 등급, 크기, 무게**를 자동으로 알아내게 하는 사전입니다.

**꼭 등록해야 하나요?**
- **아니요.** 사전 없이도 사과, 참외, 수박 등 40여 종의 과일은 자동 인식됩니다.
- 하지만 아래 경우에는 사전 등록이 필요합니다:
  - "부사"라고 적힌 걸 "사과"로 알아듣게 하고 싶을 때 (동의어)
  - 고객이 4.5kg를 주문했는데 공급처에 5kg으로 발주해야 할 때 (무게 변환)
  - 등급 표현이 다양할 때 — "프리미엄" = "특상" = "최상급" (등급 동의어)

### 과일 사전 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다. 하나씩 설명합니다:

#### ① 카테고리 (과일명)

이 사전의 **대분류 이름**입니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **카테고리** | 과일 대표 이름 1개 | `사과` |

#### ② 키워드

이 과일에 해당하는 **모든 이름**을 쉼표로 구분해서 입력합니다.
상품명에 이 키워드 중 하나라도 있으면 이 카테고리로 분류됩니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **키워드** | 이 과일의 모든 이름, 쉼표 구분 | `사과, 부사, 홍로, 시나노골드, 아오리, 감홍` |

**이게 왜 필요한가요?**
- 플랫폼에 "부사 3kg"라고 올라오면, 키워드에 "부사"가 있으니까 → "사과"로 인식
- "홍로 5kg"도 → "사과"로 인식
- 품목 검토에서 "부사 3kg"과 "사과 5kg"이 **같은 "사과" 그룹**으로 묶여서 표시됨

**어떤 키워드를 넣어야 하나요?**
- 카테고리 이름 자체: `사과`
- 품종 이름: `부사`, `홍로`, `시나노골드`, `아오리`
- 지역명이 포함된 경우: `영주사과` 등
- 플랫폼 상품명에 나올 수 있는 모든 표현을 넣으세요

#### ③ 등급 동의어 (선택)

같은 등급을 다르게 부르는 경우의 동의어입니다. **[+ 추가]** 버튼으로 그룹을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **대표명** | 등급의 표준 이름 | `특상` |
| **동의어** | 같은 뜻의 다른 표현, 쉼표 구분 | `프리미엄, 최상급, 특대, 특` |

예시: 여러 그룹을 추가할 수 있습니다
```
대표명: 특상    동의어: 프리미엄, 최상급, 특대
대표명: 상      동의어: 일반, 보통, 가정용
대표명: 중      동의어: 알뜰, 못난이
```

**이게 왜 필요한가요?**
- "프리미엄 사과 5kg"과 "특상 사과 5kg"가 있으면 → 둘 다 "특상" 등급으로 통일
- 공급처에 보내는 발주서에 등급이 통일되어 표시됩니다

#### ④ 크기 동의어 (선택)

같은 크기를 다르게 부르는 경우의 동의어입니다. **[+ 추가]** 버튼으로 그룹을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **대표명** | 크기의 표준 이름 | `대과` |
| **동의어** | 같은 뜻의 다른 표현, 쉼표 구분 | `대, 큰, 빅, L` |

예시:
```
대표명: 대과    동의어: 대, 큰, L
대표명: 중과    동의어: 중, 보통, M
대표명: 소과    동의어: 소, 작은, S
```

#### ⑤ 무게 변환 (선택)

플랫폼 주문 무게를 공급처 발주 무게로 변환하는 규칙입니다. **[+ 추가]** 버튼으로 규칙을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **원본** | 플랫폼 상품명에 적힌 무게 | `4.5kg` |
| **변환** | 공급처에 발주할 때 쓸 무게 | `5kg` |

예시: 여러 규칙을 추가할 수 있습니다
```
4.5kg → 5kg
2kg   → 3kg
1.5kg → 2kg
```

**이게 왜 필요한가요?**
- 쿠팡에 "사과 4.5kg"로 올렸는데, 공급처에는 4.5kg 규격이 없고 5kg만 있을 때
- 이 규칙이 있으면 발주서에 자동으로 "사과 5kg"으로 변환되어 나갑니다
- 규칙이 없으면 "사과 4.5kg" 그대로 나갑니다

3. 모든 입력이 끝나면 **[추가]** 클릭

### 과일 사전 수정/삭제

- **수정**: 사전 카드의 연필 아이콘 클릭 → 수정 → [수정]
- **비활성화**: 사전 카드의 토글 OFF → 매칭에서 제외 (데이터는 유지)
- **활성화 복원**: 비활성 목록에서 토글 ON
- **완전삭제**: 비활성 목록에서 🗑️ 클릭 → DB에서 완전히 삭제됨

### 과일 사전 예시 — 감귤류

실제로 이렇게 등록할 수 있습니다:

```
카테고리: 감귤
키워드: 감귤, 귤, 밀감, 하우스감귤, 노지감귤
등급 동의어:
  - 대표명: 특상 / 동의어: 로열, S급
  - 대표명: 상 / 동의어: 일반
크기 동의어:
  - 대표명: 소과 / 동의어: 2S, 꼬마
  - 대표명: 중과 / 동의어: M, 중
무게 변환:
  - 3kg → 5kg
  - 4.5kg → 5kg
```

이 사전이 있으면:
- "귤 3kg" → 감귤 카테고리, 무게 5kg으로 변환
- "밀감 4.5kg 로열" → 감귤 카테고리, 특상 등급, 무게 5kg으로 변환
- 품목 검토에서 "귤"과 "밀감"이 같은 "감귤" 그룹으로 묶임

## 10. 양식 관리 — 발주서 양식

**발주서 양식이 뭔가요?**
공급처마다 발주서 엑셀 양식이 다릅니다. A농장은 "받는분, 연락처, 상품, 수량" 순서이고, B농장은 "주문번호, 상품코드, 수량, 이름, 주소" 순서일 수 있습니다. 양식을 등록해두면 시스템이 각 공급처 양식에 맞춰서 자동으로 발주서를 만들어줍니다.

### 발주서 양식 등록하기

1. 사이드바 **매핑관리** → **공급처 관리** → 공급처 클릭하여 **상세 페이지** 진입
2. **발주서 양식** 섹션에서 **빈 양식 엑셀 파일**을 업로드합니다
   - 이 파일은 공급처에서 받은 빈 발주서 양식 파일입니다
   - 헤더만 있고 데이터는 비어있는 파일이어야 합니다
3. **시트 선택**: 엑셀에 시트가 여러 개면 데이터가 들어갈 시트를 선택
4. **헤더 행**: 컬럼 이름이 적힌 행 번호 (보통 1)
5. **데이터 시작 행**: 실제 데이터가 시작될 행 번호 (보통 2)
6. **컬럼 매핑**: 양식의 각 열에 **어떤 데이터를 넣을지** 지정합니다

### 컬럼 매핑 상세

양식의 각 열이 나열됩니다. 각 열의 드롭다운에서 넣을 데이터를 선택합니다:

| 선택값 | 뭐가 들어가나요? |
|--------|-----------------|
| **매칭키 (배송/상품번호)** | 쿠팡: 묶음배송번호:옵션ID, 토스: 주문상품번호 |
| **주문번호** | 플랫폼 주문번호 |
| **주문상품번호** | 주문 내 상품번호 |
| **공급처 상품명** | 상품명 변환 규칙이 적용된 이름 (없으면 원본) |
| **플랫폼 상품명** | 쿠팡=노출상품명(옵션명), 토스=상품명+옵션명 |
| **공급처 상품코드** | 상품명 변환에서 등록한 코드 |
| **수량** | 주문 수량 |
| **수취인명** | 받는 사람 이름 |
| **수취인 연락처** | 받는 사람 전화번호 |
| **우편번호** | 우편번호 |
| **주소** | 배송 주소 |
| **배송메시지** | 배송 시 요청사항 |
| **주문자명** | 주문한 사람 이름 |
| **주문자 연락처** | 주문한 사람 전화번호 |
| **주문일시** | 주문 날짜/시간 |
| **보내는분 주소** | 수취인 주소와 동일 |
| **빈 칸** | 아무것도 안 넣음 |

**전화번호 형식**: 수취인/주문자 연락처를 선택하면 형식을 추가로 지정합니다:
- **원본**: 플랫폼에서 받은 그대로 (예: 010-1234-5678)
- **하이픈**: 하이픈 형식 (예: 010-1234-5678)
- **숫자만**: 숫자만 (예: 01012345678)

7. **[저장]** 클릭

> **"공급처 상품명"과 "플랫폼 상품명" 차이가 뭔가요?**
> - **공급처 상품명**: "상품명 변환" 규칙이 적용된 이름. 공급처가 알아보는 이름.
>   예: "사과 3kg", "참외 혼합 5kg"
> - **플랫폼 상품명**: 쿠팡/토스에 올라가 있는 원본 이름.
>   예: "프리미엄 산지직송 사과 세트 3kg", "[특가] 성주 꿀참외 혼합과 5kg"
> - 공급처가 "원본 상품명 그대로 보내줘"라고 하면 → **플랫폼 상품명** 선택
> - 공급처가 "우리 상품코드/이름으로 보내줘"라고 하면 → **공급처 상품명** 선택

## 11. 양식 관리 — 운송장 양식

사이드바 **운송장 양식** 클릭

**운송장 양식이 뭔가요?**
쿠팡/토스 셀러 페이지에서 운송장을 일괄 등록할 때 사용하는 엑셀 양식 파일입니다. 시스템이 이 양식에 택배사명과 운송장번호를 자동으로 채워줍니다.

### 운송장 양식 등록하기

1. **플랫폼** 선택 (쿠팡 또는 토스)
2. 해당 플랫폼의 **빈 운송장 양식 파일**을 업로드
   - 쿠팡/토스 셀러 페이지에서 "운송장 일괄 등록" 양식을 다운로드
3. **시트명** 선택
4. **헤더 행** 입력 (컬럼명이 있는 행 번호)
5. **데이터 시작 행** 입력
6. **컬럼 위치** 설정:

| 설정 | 뭔가요? | 예시 |
|------|---------|------|
| **매칭키 컬럼** | 발주서의 매칭번호가 있는 열 번호 | 쿠팡: 묶음배송번호:옵션ID, 토스: 주문상품번호 열 |
| **택배사 컬럼** | 택배사명을 채울 열 번호 | 쿠팡: D열(4) |
| **운송장번호 컬럼** | 운송장번호를 채울 열 번호 | 쿠팡: E열(5) |
| **주문상태 컬럼** (토스만) | "배송중"을 채울 열 | 토스: D열(4) |
| **주문상태 값** (토스만) | 채울 텍스트 | `배송중` |

7. **[저장]** 클릭

> 플랫폼이 양식을 변경했을 때는 새 양식 파일을 다시 올리고 컬럼 위치를 확인하세요.

| **최근 작업건** | 최근 작업건 목록 — 상태별 색상 표시 |
| **바로가기** | 매핑관리, 양식 설정 등으로 빠르게 이동 |

**작업건 상태 색상:**
- **파란색**: 진행중 (아직 작업 중)
- **노란색/초록색**: 발주완료 (운송장 대기)
- **회색**: 완료

작업건을 클릭하면 해당 단계로 바로 이동합니다.

## 13. 자주 묻는 질문 (FAQ)

### 새 품목이 나왔을 때 어떻게 하나요?

공급처 배정 페이지에서 **"미분류"** 그룹에 표시됩니다.
공급처를 선택하면 → 자동으로 품목 매핑에 등록됨 → 다음부터는 자동 배정됩니다.

### 공급처를 오늘만 바꾸고 싶어요

배정 페이지에서 공급처 칩을 클릭 → 새 공급처 선택 → **"오늘만 변경"** 선택.
내일은 원래 공급처로 자동 배정됩니다.

### 공급처를 영구적으로 바꾸고 싶어요

배정 페이지에서 공급처 칩을 클릭 → 새 공급처 선택 → **"기본 변경"** 선택.
또는 품목 검토에서 공급처를 바꾸고 **"기본 저장"** 체크.

### 운송장이 매칭 안 돼요

매칭번호가 일치하지 않는 경우입니다.
- 매칭 결과에서 빨간색 **"미매칭"** 행의 **[수동 매칭]** 클릭
- 주문 목록에서 올바른 주문을 찾아 클릭
- 공급처가 매칭번호를 잘못 적은 경우가 많습니다

### 토스 엑셀이 안 올라가요

토스 엑셀은 특수한 구조입니다. **원본 파일을 수정 없이 그대로** 올려야 합니다.
엑셀을 열어서 저장하면 시트 이름이 바뀌어 파싱에 실패할 수 있습니다.

### 쿠팡 파일이 여러 개예요

두 번째 파일 업로드 시 **"별도 파일로 업로드"** 선택하면 "쿠팡1", "쿠팡2"로 따로 관리됩니다. 운송장 다운로드도 각각 분리되어 나옵니다.

### 과일 사전 꼭 등록해야 하나요?

아닙니다. 사과, 참외, 수박 등은 사전 없이도 자동 인식됩니다.
**"부사"를 "사과"로 묶기**, **무게 변환(4.5kg→5kg)** 같은 기능이 필요할 때만 등록하세요.

### 간편 운송장은 뭔가요?

작업건 없이 주문 파일과 운송장 파일만 넣으면 바로 매칭해주는 빠른 모드입니다.
운송장 페이지 오른쪽 위 **[간편 운송장]** 버튼으로 시작합니다.
다만 DB에 저장되지 않으므로, 페이지를 나가면 데이터가 사라집니다.

### 발주 완료 후 수정하고 싶어요

발주서 다운로드 페이지의 **[발주 되돌리기]** 클릭 → "진행중"으로 돌아감 → 수정 가능.

### 운송장 파일을 잘못 다운로드했어요

같은 페이지에서 다시 다운로드하면 됩니다. 횟수 제한 없습니다.

### "작업건"이 정확히 뭔가요?

하루에 한 번 만드는 "오늘의 발주 작업 묶음"입니다.
오늘 올린 주문, 배정, 발주서, 운송장이 이 작업건 안에 관리됩니다.
과거 작업건도 목록에서 확인할 수 있어서, "5월 12일에 A농장에 뭘 보냈지?" 같은 이력 확인이 가능합니다.

### 보내는분 정보는 어떻게 되나요?

발주서의 "보내는분" 관련 칸은 항상 비어있거나 수취인 주소가 들어갑니다.
실제 발신자 정보는 공급처에서 직접 관리합니다.
