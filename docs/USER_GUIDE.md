# WithLab 사용 가이드

과일 발주 관리 시스템 운영 가이드입니다.

---

## 1. 시작하기

### 접속

PC Chrome 브라우저에서 배포된 URL로 접속합니다.

### 로그인

- 이메일과 비밀번호를 입력하고 로그인합니다.
- 계정은 관리자가 Supabase에서 생성합니다.
- 로그인 후 대시보드가 표시됩니다.

---

## 2. 매일 운영 순서 요약

매일 아침 발주 작업의 전체 흐름입니다.

1. 로그인
2. 대시보드에서 **[새 발주 작업 시작]** 클릭
3. 쿠팡 주문 엑셀 업로드
4. 토스 주문 엑셀 업로드
5. 공급처 배정 확인 (미분류 있으면 공급처 지정)
6. 공급처별 발주서 다운로드
7. 공급처에 발주서 전달 (카톡, 이메일 등)
8. **[발주 완료 처리]** 클릭
9. 공급처에서 운송장 수신 후 **[운송장 매칭 시작]**
10. 공급처별 운송장 엑셀 업로드
11. 매칭 결과 확인 (미매칭 있으면 수동 매칭)
12. 쿠팡/토스 운송장 파일 다운로드
13. 각 플랫폼에 운송장 업로드 (쿠팡/토스 셀러 페이지)

---

## 3. 발주서 상세

### 주문 업로드

1. 대시보드에서 **[새 발주 작업 시작]** 클릭 → 작업건 이름 입력 → **[만들기]**
2. **쿠팡 주문 엑셀** 파일을 드래그하거나 클릭하여 업로드
   - Delivery 시트에서 주문 데이터를 자동 파싱합니다
   - 정상/오류/중복 건수가 표시됩니다
3. **토스 주문 엑셀** 파일도 같은 방식으로 업로드
   - 주문내역 시트의 5행부터 데이터를 파싱합니다
4. 업로드 완료 후 **[공급처 배정으로 이동]** 클릭

> 같은 플랫폼의 엑셀을 다시 업로드하면 기존 데이터를 덮어씁니다.

### 공급처 배정

1. 업로드된 주문이 품목별로 자동 배정됩니다
2. **미분류** 그룹이 있으면 공급처를 지정해야 합니다
   - 미분류 주문의 **[공급처 선택]** 클릭
   - 공급처 선택 시 품목 매핑에 자동 등록됩니다
3. 필요하면 공급처를 변경할 수 있습니다
   - 주문 행의 공급처 칩을 클릭하여 변경
   - "오늘만 변경" 또는 "기본 변경"을 선택할 수 있습니다
4. 배정 확인 후 **[발주서 다운로드로 이동]** 클릭

### 발주서 다운로드

1. 공급처별 발주서 카드가 표시됩니다
2. 각 카드에서 **[다운로드]** 클릭 → 공급처 양식에 맞는 엑셀 파일이 생성됩니다
3. **[전체 다운로드]** 클릭하면 모든 공급처 발주서를 한 번에 다운로드합니다
4. 발주서를 확인한 후 **[발주 완료 처리]** 클릭

> 발주 완료 처리 후에는 운송장 관련 작업만 가능합니다.

### 발주 완료 처리

- 발주 완료 처리를 하면 작업건 상태가 "발주완료"로 변경됩니다
- 이후 운송장 업로드/매칭 작업을 진행할 수 있습니다

---

## 4. 운송장 처리 상세

### 운송장 업로드

1. 대시보드에서 "발주완료" 상태의 작업건을 클릭하면 운송장 페이지로 이동합니다
2. 공급처별로 운송장 엑셀 파일을 업로드합니다
   - 업로드 시 공급처를 선택합니다
   - 운송장 데이터가 자동으로 파싱되고 주문과 매칭됩니다
3. 파싱 결과(정상/오류 건수)를 확인합니다

### 매칭 결과 확인

1. 매칭 결과 탭에서 전체 매칭 현황을 확인합니다
   - **매칭**: 주문번호가 일치하여 자동으로 연결된 건
   - **미매칭**: 일치하는 주문을 찾지 못한 건
   - **중복**: 같은 주문에 여러 운송장이 연결된 건
2. 미매칭 건은 수동으로 주문을 지정할 수 있습니다

### 수동 매칭

1. 미매칭 운송장 행의 **[수동 매칭]** 클릭
2. 주문 목록에서 맞는 주문을 선택합니다
3. 매칭이 완료되면 상태가 업데이트됩니다

### 플랫폼 파일 다운로드

1. 매칭 완료 후 플랫폼 다운로드 탭으로 이동합니다
2. **쿠팡 운송장 파일 다운로드**: D열 택배사, E열 운송장번호가 채워진 파일
3. **토스 운송장 파일 다운로드**: D열 주문상태 "배송중", F열 택배사, G열 송장번호가 채워진 파일
4. 다운로드한 파일을 각 플랫폼 셀러 페이지에서 업로드합니다

---

## 5. 매핑 관리

사이드바 **설정** 섹션에서 관리합니다.

### 공급처 추가/수정

- 사이드바 → **공급처 관리**
- **[추가]** 클릭 → 공급처명, 연락처, 메모 입력
- 기존 공급처 클릭 → 수정 가능
- 비활성화한 공급처는 배정 대상에서 제외됩니다

### 품목 ↔ 공급처 매핑

- 사이드바 → **품목 매핑**
- 상품명에서 추출된 품목과 공급처를 연결합니다
- 새 품목이 나오면 자동배정 시 "미분류"로 표시됩니다 → 공급처를 지정하면 매핑에 자동 추가

### 상품명 변환

- 사이드바 → **상품명 변환**
- 플랫폼 상품명을 공급처용 이름으로 변환하는 규칙을 관리합니다
- 예: "프리미엄 사과 세트 5kg" → "사과 5kg"

### 택배사 매핑

- 사이드바 → **택배사 매핑**
- 공급처에서 사용하는 택배사명을 플랫폼(쿠팡/토스) 표준명으로 변환합니다
- 예: "CJ대한통운" → "CJ대한통운" (쿠팡), "CJ대한통운" (토스)

---

## 6. 양식 관리

### 공급처 발주서 양식 등록

- 사이드바 → **발주서 양식**
- 공급처별로 빈 엑셀 양식 파일을 업로드합니다
- 시트 선택 → 컬럼 매핑 (어떤 열에 무슨 데이터를 넣을지 설정)
- 데이터 시작 행과 전화번호 형식을 지정합니다

### 플랫폼 운송장 양식 등록

- 사이드바 → **운송장 양식**
- 쿠팡/토스 운송장 업로드 양식 파일을 등록합니다
- 택배사 열, 운송장번호 열 등 컬럼 위치를 지정합니다

---

## 7. 자주 묻는 질문

### 새 품목이 나왔을 때

공급처 배정 페이지에서 "미분류" 그룹에 표시됩니다. 해당 품목에 공급처를 지정하면 자동으로 품목 매핑에 추가됩니다.

### 공급처를 변경하고 싶을 때

공급처 배정 페이지에서 주문 행의 공급처 칩을 클릭하여 변경합니다. "오늘만 변경"과 "기본 변경" 중 선택할 수 있습니다.

### 운송장이 매칭 안 될 때

주문번호가 일치하지 않는 경우입니다.
- 매칭 결과에서 "미매칭" 탭을 확인합니다
- **[수동 매칭]**을 클릭하여 올바른 주문을 직접 선택합니다
- 공급처가 주문번호를 잘못 기재한 경우가 많습니다

### 토스 엑셀이 파싱되지 않을 때

토스 엑셀은 특수한 구조입니다 (1~4행 메타데이터). 토스 셀러 페이지에서 다운로드한 원본 파일을 그대로 업로드해야 합니다. 엑셀 편집 후 저장하면 시트 이름이 변경될 수 있어 파싱에 실패할 수 있습니다.

### 같은 플랫폼을 다시 업로드하고 싶을 때

같은 작업건에서 같은 플랫폼의 엑셀을 다시 업로드하면 기존 데이터가 삭제되고 새로 생성됩니다. 확인 모달에서 **[재업로드]**를 클릭합니다.
