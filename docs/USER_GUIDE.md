## 1. 시작하기

### 접속 및 로그인

1. PC에서 **Chrome 브라우저**를 엽니다
2. 주소창에 배포된 URL을 입력합니다
3. 로그인 화면이 나옵니다:
   - **아이디**: 발급받은 아이디 입력 (이메일 전체를 넣어도 됩니다)
   - **비밀번호**: 발급받은 비밀번호 입력
   - **[로그인]** 버튼 클릭
4. 로그인 성공하면 **대시보드** 화면이 나옵니다

> 계정은 관리자가 별도로 생성해드립니다. 비밀번호를 잊으셨으면 관리자에게 문의하세요.

### 화면 구성

화면 **왼쪽에 사이드바** 메뉴가 있습니다. 여기서 원하는 페이지로 이동합니다.

| 메뉴 | 위치 | 무슨 페이지? |
|------|------|-------------|
| **대시보드** | 맨 위 | 오늘 할 일 한눈에 보기, 빠른 시작 버튼 |
| **발주서** | 주문 관리 | 주문 엑셀 올리고 → 공급처별 발주서 만들기 |
| **운송장** | 주문 관리 | 운송장 올리고 → 쿠팡/토스에 올릴 파일 만들기 |
| **매핑관리** | 설정 | 공급처, 품목, 상품명, 택배사, 과일사전 관리 |
| **운송장 양식** | 설정 | 쿠팡/토스 운송장 양식 파일 관리 |
| **사용 가이드** | 맨 아래 | 이 가이드 (앱 안에서도 볼 수 있음) |

### 다크모드 / 라이트모드

사이드바 아래쪽 **테마 버튼**을 누르고 시스템, 라이트, 다크 중 하나를 고릅니다.

### 로그아웃

사이드바 맨 아래 계정 메뉴에서 로그아웃합니다.

## 2. 매일 운영 순서 요약

매일 아침 이 순서대로 진행하면 됩니다.

```
① 로그인 → 대시보드에서 [새 발주 작업 시작] 클릭
② 쿠팡, 토스 주문 엑셀을 하나씩 업로드
③ 품목 검토 — 오늘 주요 품목의 공급처를 미리 선택 (건너뛰어도 됨)
④ 공급처 배정 확인 — "미분류", "추천", "가격 미확인" 처리
⑤ 공급처별 발주서 다운로드 → 카톡이나 이메일로 공급처에 전달
⑥ [발주 완료 처리] 클릭
⑦ (공급처에서 운송장 보내주면) 운송장 엑셀 업로드
⑧ 매칭 결과 확인 — "미매칭"이 있으면 수동으로 연결
⑨ 쿠팡/토스 운송장 파일 다운로드 → 각 플랫폼 셀러 페이지에 업로드
⑩ [운송장 처리 완료] 클릭
```

## 3. 발주서 — 단계별 상세

### 3-1. 작업건 만들기

**"작업건"이 뭔가요?**
발주 한 번을 묶는 단위입니다. 그때 올린 주문, 배정, 발주서, 운송장이 이 작업건 안에 묶입니다.

**만드는 방법:**
1. 사이드바에서 **발주서** 클릭
2. **[새 작업건]** 버튼 클릭 (대시보드에서는 **[새 발주 작업 시작]**)
3. 작업건 이름을 입력합니다 (자동으로 "2026-05-14 오전" 같이 채워져 있음)
4. **[만들기]** 클릭

> 이전에 만든 작업건을 이어서 하려면 목록에서 클릭하세요. 진행중 작업건은 주문 업로드, 발주완료·완료 작업건은 발주서 다운로드 화면으로 이동합니다. 진행중 작업건의 위쪽 탭으로는 앞 단계로만 돌아갈 수 있고, 다음 단계로는 화면 아래 버튼으로 넘어갑니다. 발주완료·완료 작업건은 모든 탭을 누를 수 있습니다.

### 3-2. 주문 엑셀 업로드

**여기서 할 일:** 쿠팡/토스 셀러 페이지에서 다운받은 주문 엑셀 파일을 시스템에 올립니다.

#### 파일 올리기

1. **"주문 엑셀 파일을 끌어다 놓거나 클릭"** 영역에 파일을 올립니다. 쿠팡/토스는 자동으로 구분됩니다.
2. 파일이 자동으로 읽히고, 결과가 표시됩니다:
   - **정상 243건**: 잘 읽힌 주문 수
   - **오류 2건**: 필수 정보가 빠진 행 (행 번호랑 이유가 나옴)
   - **중복 0건**: 같은 매칭번호가 2번 나온 건
3. 오류 건은 빠지고 정상 건만 처리됩니다.
4. 쿠팡, 토스 파일을 하나씩 같은 방식으로 올립니다.

.xlsx, .xls 파일만 올릴 수 있고 최대 10MB입니다.

#### 같은 플랫폼 파일을 또 올릴 때

쿠팡이든 토스든 같은 플랫폼 파일을 또 올리면 팝업이 뜹니다:

| 선택 | 결과 |
|----|----|
| **기존 주문에 추가** | 기존 주문·배정·운송장을 유지하고 새 주문만 추가합니다. 중복은 자동 제외됩니다. 파일이 여러 개면 추가할 파일을 선택합니다. 이미 배정한 작업건이면 새 주문은 업로드 직후 자동 배정됩니다. |
| **별도 파일** | "쿠팡1", "쿠팡2"로 따로 관리됩니다. 이 이름은 가격정리와 운송장 다운로드 화면에 나오고, 업로드 화면의 파일 목록에는 "쿠팡"과 파일명만 나옵니다. 운송장 파일도 따로 나옵니다. 기존 주문과 겹치면 올라가지 않습니다. |
| **교체하기** | 이 플랫폼의 기존 주문을 지우고 새 파일로 대체합니다. 파일이 여러 개면 모두 삭제되고 배정도 함께 삭제됩니다. |

파일 목록의 **[교체]**를 눌러 파일을 골라도 바로 교체되지 않고 같은 선택 창이 뜹니다.

> 주의: 파일 목록의 **[삭제]**는 확인창 없이 바로 삭제됩니다. 발주 완료 후에는 주문을 올리거나 교체할 수 없습니다.

#### 다 올렸으면

화면 아래의 **[다음: 품목 검토]** 버튼을 클릭합니다.

### 3-3. 품목 검토 (건너뛰어도 됨)

**여기서 할 일:** 오늘 주문된 주요 품목(사과, 참외, 귤 등)을 보고, 각 품목을 어느 공급처에 보낼지 미리 정합니다.

> 이 단계는 **선택 사항**입니다. **[건너뛰기]**를 누르면 등록된 매핑 기준으로 자동 배정이 바로 실행됩니다. 이미 배정된 작업건이면 여기서 고른 공급처가 바로 반영되지 않습니다. **[배정 시작]**으로 넘어간 뒤 **[재배정]**을 누르면 반영되지만, 손으로 바꾼 배정은 사라집니다.
> 매일 공급처가 바뀌는 품목이 있을 때 유용합니다.

#### 화면에 보이는 것

테이블에 오늘 주문된 품목이 **주문 건수 많은 순서**로 나열됩니다:

| 열 | 설명 | 예시 |
|----|------|------|
| **#** | 순번 | 1 |
| **품목** | 주문에서 추출된 과일 이름 | 사과, 참외, 한라봉 |
| **플랫폼** | 이 품목이 들어온 플랫폼 | 쿠팡, 토스 |
| **건수** | 이 품목의 주문 건수 | 120건 |
| **수량** | 이 품목의 총 수량 (박스 등) | 360 |
| **공급처** | 드롭다운 — 여기서 공급처를 선택 | [A농장 ▾] |
| **기본 저장** | 체크박스 — 다음 품목 검토의 추천에 표시할지 | ☐ |

#### 공급처 드롭다운을 클릭하면

추천 공급처가 **맨 위에** 표시됩니다. 각 추천 옆에 이유가 나옵니다:

| 표시 | 의미 |
|------|------|
| 🔵 **기본** | 품목 매핑에 기본으로 등록된 공급처 |
| 🟢 **전날** | 가장 최근 발주완료·완료 작업건에서 이 품목을 보낸 공급처 |
| 🟡 **최다** | 최근 30일 발주완료·완료 작업건에서 이 품목을 보낸 공급처와 보낸 횟수. 상품명마다 가장 많이 보낸 곳을 하나씩 보여 주므로 품목 전체 1등과 다를 수 있음 |
| 💰 **최저가** | 상품 목록 기준 가격이 가장 싼 공급처 (품절·가격 없음 제외) |

추천 아래에 나머지 공급처 전체 목록이 나옵니다. 맨 아래의 **"미배정"**을 고르면 그 품목의 지정이 해제됩니다.

#### "기본 저장" 체크박스

추천 1순위와 다른 공급처를 고르면 체크박스가 나타납니다. 추천이 없는 품목에는 나오지 않습니다.

- **체크하면** → **[배정 시작]**을 누를 때 품목 매핑에 공통 매핑으로 저장됩니다. 상품명 칸에는 "사과"처럼 품목 이름이 들어갑니다. 다음 품목 검토의 추천에 "기본"으로 표시되지만 자동으로 선택되지는 않습니다. 상품명이 품목 이름과 똑같은 주문이 아니면 자동 배정에도 쓰이지 않습니다.
- **체크 안 하면** → 이번 작업건에만 이 공급처로 배정됩니다.

다음부터 상품별로 자동 배정되게 하려면 공급처 배정의 **[기본 매핑도 변경]**을 쓰세요.

#### 다 선택했으면

- **[배정 시작]** 클릭 → 고른 공급처를 반영해 자동 배정이 시작됩니다. 고르지 않은 품목은 매핑 기준으로 배정됩니다.
- **[건너뛰기]** 클릭 → 품목 검토 없이 매핑 기준으로 자동 배정됩니다.

> **품목 그룹핑은 어떻게 되나요?**
> 시스템이 상품명에서 과일 이름을 자동으로 뽑습니다.
> - "고당도 사과 3kg", "사과 5kg" → 둘 다 "사과"로 묶임
> - 과일 사전에 동의어를 등록하면 "부사"도 "사과"로 묶을 수 있습니다 (→ 9장 참고)
> - 과일 사전이 없어도 사과, 참외, 수박 등 40여 종은 품목 검토에서 묶입니다. 공급처 상품을 자동으로 찾으려면 사전 등록이 필요합니다
> - 품목 검토에서 고른 주문은 공급처 배정에서 "수정됨"으로 표시됩니다

### 3-4. 공급처 배정

**여기서 할 일:** 시스템이 자동 배정한 결과를 확인하고, 틀린 것만 수정합니다.

#### 화면에 보이는 것

상품, 옵션, 공급처별로 한 행씩 표시됩니다. 행을 펼치면 주문 목록이 보입니다. 정렬은 가나다순, 건수 많은 순, 공급처별 중에서 고릅니다.

```
▶ 사과 3kg   1박스    12건 · 총 12개   자동배정  [A농장 ▾]
▶ 참외 5kg   혼합과    8건 · 총 9개    자동배정  [B농장 ▾]
▶ 블루베리    1kg      3건 · 총 3개    미분류    [공급처 선택 ▾]
```

주문이 전부 미분류로 보이면 **[자동배정]**을 누르세요.

#### "미분류" 처리하기

**미분류**는 매핑이 없거나 후보 공급처가 모두 품절이라 배정하지 못한 주문입니다.

1. 미분류 행의 **[공급처 선택]** 드롭다운을 클릭
2. 공급처를 선택합니다
3. **[오늘만 적용]** 또는 **[매핑 등록 + 적용]**을 클릭합니다

> 미분류에서는 [오늘만 적용]을 눌러도 같은 플랫폼의 같은 상품·옵션 매핑이 등록됩니다. 다음에 같은 상품이 오면 자동 배정됩니다.

#### "추천" 처리하기

매핑은 없지만 공급처 상품과 비슷해서 시스템이 후보를 제안한 주문입니다. 적용하면 매핑도 함께 저장됩니다.

| 버튼 | 동작 |
|----|----|
| **[전체 추천 적용]** | 추천을 모두 1순위 공급처로 적용 |
| **[추천만 보기]** | 추천 품목만 목록에 표시 |
| 행의 **[○○ 적용]** | 그 품목만 추천 공급처로 적용 |
| 행의 **[변경]** | 다른 공급처를 직접 선택 |

#### 이미 배정된 공급처 바꾸기

1. 품목 행의 **공급처 드롭다운**을 클릭
2. 새 공급처를 선택합니다
3. 선택지가 나옵니다:
   - **[오늘만 적용]** → 이번 작업건에서만 적용. "수정됨"으로 표시됩니다.
   - **[기본 매핑도 변경]** → 이 플랫폼의 같은 상품·옵션 품목 매핑에서 새 공급처가 기본이 됩니다(매핑이 없었으면 새로 만듦). 다음부터는 새 공급처가 품절이 아니면 그쪽으로 배정됩니다.

그 행의 주문 전체가 바뀝니다. 일부만 바꾸려면 **[분배]**를 쓰세요.

#### 한 품목을 여러 공급처에 나누기 (수량 분배)

예: 사과 100건 중 60건은 A농장, 40건은 B농장으로 보내고 싶을 때

1. 품목 행의 **[분배]** 버튼 클릭 (공급처가 배정된 주문이 2건 이상인 행에만 표시. 미분류 행은 먼저 공급처를 지정)
2. **[+ 공급처 추가]**로 공급처를 넣고 공급처별 건수를 입력합니다 (합계가 전체 건수와 같아야 합니다)
3. **[적용]** 클릭하면 주문이 나뉩니다

> 주의: 1건의 주문을 쪼개는 건 안 됩니다. "사과 3개 주문"을 A 2개 + B 1개로 나누는 건 불가.
> "주문 100건" 중 60건/40건으로 나누는 것만 가능합니다.

#### 가격 미확인 확인하기

공급처는 배정됐지만 단가가 없는 품목입니다. 예상 발주금액에서 빠지고 가격정리의 단가도 비게 됩니다.

1. **[가격 미확인만 보기]**를 클릭합니다.
2. 품목의 **가격 미확인** 뱃지에 마우스를 올려 사유를 확인합니다.
3. 사유에 따라 처리합니다.

| 뱃지 안내 | 할 일 |
|----|----|
| 상품 목록이 없습니다 | 상품 목록 갱신 후 발주 상품 선택 |
| 발주 상품을 하나로 찾지 못했습니다 | 발주 상품을 눌러 직접 선택. 같은 표현이 또 나오면 과일 사전에 추가 |
| 상품 목록에 가격이 없습니다 | 공급처 파일의 가격 확인 후 상품 목록 갱신 |
| 배정에 반영되지 않았습니다 | 발주 상품을 눌러 같은 상품을 다시 선택 |

가격 미확인이 있으면 **[다음: 발주서 다운로드]**를 누를 때 확인창이 뜹니다. 가격이 없어도 발주해야 하면 **[그대로 진행]**을 누르세요.

#### 목록 거르기

- **상태**: 전체, 자동배정, 추천, 미분류, 수정됨, 가격 미확인
- **과일**: 감귤, 사과처럼 과일별로 보기. 사전에 없는 과일은 "기타"
- **공급처**: 공급처별로 보기

#### 상품 목록 갱신과 재배정

공급처 가격표가 바뀌면 **[상품 목록 갱신]**에서 공급처 파일을 올립니다. 이미 배정된 주문의 단가는 자동으로 바뀌지 않으니, 발주 상품을 눌러 다시 선택하세요.

> 주의: **[재배정]**은 작업건 전체의 배정을 지우고 처음부터 다시 합니다. 손으로 바꾼 공급처와 상품도 사라집니다.

#### 다 확인했으면

**[다음: 발주서 다운로드]** 버튼을 클릭합니다. 미분류나 추천이 남아 있으면 버튼이 눌리지 않습니다.

### 3-5. 발주서 다운로드

**여기서 할 일:** 공급처별 발주서 엑셀 파일을 다운로드해서 공급처에 보냅니다.

#### 화면에 보이는 것

공급처별로 카드가 나옵니다:

```
┌──────────────────────────────┐
│ A농장                        │
│ 주문 120건 · 수량 360개      │
│            [다운로드]  🗑️    │
└──────────────────────────────┘

┌──────────────────────────────┐
│ B농장                        │
│ 주문 95건 · 수량 285개       │
│            [다운로드]  🗑️    │
└──────────────────────────────┘
```

#### 다운로드 방법

- **개별 다운로드**: 각 카드의 **[다운로드]** 클릭 → 해당 공급처 발주서 엑셀 파일 1개 다운로드
- **전체 다운로드**: 상단의 **[전체 다운로드]** 클릭 → 공급처별 파일이 각각 내려받아집니다. 양식 미등록 공급처는 제외됩니다.

> **"양식이 등록되지 않았습니다"가 보이면?**
> 카드의 **[양식 관리]** 링크에서 해당 공급처의 발주서 양식을 등록하세요 (10장 참고).

#### 발주서를 공급처에 보내기

다운로드한 엑셀 파일을 카카오톡, 이메일 등으로 공급처에 보냅니다.

#### 가격정리 다운로드

발주서 카드 아래 **가격정리**에서 주문 목록별로 구매가격과 판매금액이 들어간 엑셀을 내려받습니다. 발주 완료 전에도 받을 수 있습니다.

| 버튼 | 동작 |
|----|----|
| **[금액 확인]** | 주문별 단가, 구매가격, 판매금액 확인 |
| **[다운로드]** | 최초 파일명에 "_가격정리"를 붙여 저장 |
| **[새로고침]** | 배정을 바꾼 뒤 최신 내용으로 다시 불러오기 |

단가가 없거나 미배정인 주문이 있으면 금액 확인 창이 뜨고, **[빈칸으로 다운로드]**를 누르면 그 금액만 비워서 받습니다. 택배사와 운송장번호는 운송장 3단계에서 복사해 넣습니다 (4-1 참고).

### 3-6. 발주 완료 처리

모든 발주서를 보냈으면:

1. **[발주 완료 처리]** 버튼 클릭
2. 안내를 확인하고 **[발주 완료]** 클릭
3. 작업건 상태가 **"발주완료"** 로 바뀝니다

미배정 주문이 있으면 완료되지 않습니다. 양식 미등록 공급처가 있으면 수동 발주 확인을 체크하세요. 진행중 작업건도 배정이 있으면 운송장을 올릴 수 있습니다. 발주 완료 후에는 주문을 올리거나 교체할 수 없습니다.

### 3-7. 발주 되돌리기

"발주완료 했는데 배정을 수정해야 할 때":

1. 발주서 다운로드 페이지 상단의 초록 배너에서 **[발주 되돌리기]** → 확인창의 **[되돌리기]** 클릭
2. 작업건이 **"진행중"** 상태로 돌아갑니다
3. 배정을 수정하고 다시 [발주 완료 처리]를 할 수 있습니다
4. 기존 배정은 그대로 유지됩니다

운송장 처리까지 완료한 작업건은 되돌릴 수 없습니다.

### 3-8. 공급처별 배정 삭제

특정 공급처의 배정만 취소하고 싶을 때:

1. 발주서 다운로드 페이지에서 해당 공급처 카드의 🗑️ → 확인창의 **[삭제]** 클릭
2. 해당 주문이 **"미분류"** 상태가 됩니다
3. 배정 페이지로 가서 다시 배정할 수 있습니다
4. **"진행중"** 상태에서만 가능합니다 (발주완료 후에는 먼저 되돌리기를 해야 함)

### 3-9. 작업건 삭제

잘못 만든 작업건을 삭제할 때:

1. 발주서 작업건 목록에서 해당 작업건 오른쪽의 🗑️ 아이콘 클릭
2. "작업건 삭제" 창에서 **[삭제]** 클릭
3. 이 작업건에 속한 **모든 데이터(주문, 배정, 운송장)가 삭제**됩니다
4. **되돌릴 수 없습니다** — 신중하게 클릭하세요

## 4. 운송장 처리 — 단계별 상세

운송장 처리에는 **2가지 방식**이 있습니다:

| 방식 | 언제 쓰나요? |
|------|-------------|
| **일반 운송장** | 매칭 결과를 상세히 보고 싶을 때, 미매칭을 수동으로 처리해야 할 때 |
| **간편 운송장** | 빠르게 처리하고 싶을 때. 작업건 없이 바로 파일만 넣으면 됨 |

### 4-1. 일반 운송장

#### 운송장 업로드

1. 사이드바에서 **운송장** 클릭
2. 작업건 목록에서 처리할 작업건 클릭 (배정이 없는 작업건은 선택할 수 없습니다)
3. 운송장 업로드 화면이 나옵니다
4. **공급처를 먼저 선택합니다** (드롭다운에서 선택)
5. 운송장 엑셀 파일을 **드래그하거나 클릭해서 업로드**
6. 파싱 결과가 표시됩니다 (정상/오류 건수)
7. 다른 공급처의 운송장도 같은 방식으로 업로드합니다

> **잘못 올린 운송장 삭제**: 업로드 현황 카드에 마우스를 올려 🗑️ 클릭 → 확인 → 삭제됨

> **같은 공급처 파일을 또 올리면** 추가되지 않고 대체됩니다. 나눠 받은 파일은 합쳐서 올리세요.

> **"주문번호 없는 운송장 N행을 건너뛰었습니다"**: 운송장번호는 있는데 어느 주문인지 알 수 없는 행이 있다는 뜻입니다. 한 주문을 여러 박스로 나눈 행이 아니라면 공급처 파일의 주문번호를 확인하세요.

#### 매칭 결과 확인

**매칭 결과** 탭을 클릭하면 운송장과 주문의 매칭 현황이 나옵니다.

**공급처별 매칭 진행률:**
통계 위에 공급처별 칩이 표시됩니다:
- ✅ **초록 체크 + 공급처명** → 이 공급처 운송장 100% 매칭 완료
- **원형 프로그레스 + "매칭 58/60"** → 아직 진행 중 (60건 중 58건 매칭)

**상단 통계 카드:**
| 카드 | 의미 |
|------|------|
| **매칭됨** | 주문과 자동 연결된 건 |
| **미매칭** | 연결할 주문을 못 찾은 건 |
| **중복** | 같은 주문에 운송장이 2개 이상인 건 |
| **오류** | 형식이 틀렸거나 필수값이 빠진 건 |

**테이블:**
각 운송장 행에 매칭 상태가 색상으로 표시됩니다:
- **초록 "매칭됨"** → 정상
- **노란 "미매칭"** → 수동 처리 필요
- **주황 "중복"** → 확인 필요
- **빨간 "오류"** → 공급처 파일 확인

> **필터**: 상태 필터와 공급처 필터(공급처가 2곳 이상일 때)로 원하는 건만 볼 수 있습니다.

> **건너뛰기**: **[무효 건 전체 건너뛰기]**, **[중복 건 전체 건너뛰기]**로 처리하지 않을 건을 한꺼번에 넘깁니다. 건별로는 건너뛸 수 없고, 건너뛴 행은 흐리게 표시되며 되돌릴 수 없습니다.

#### 수동 매칭 (미매칭 처리하기)

미매칭이 있으면 직접 주문을 연결해야 합니다:

1. "미매칭" 행의 **[수동 매칭]** 클릭
2. 주문 목록 팝업이 뜹니다 (올린 공급처에 배정된 주문만 표시됩니다)
3. 주문을 찾아 **[연결]** 클릭
4. 매칭 완료 → 상태가 "매칭됨"으로 바뀝니다

> 이미 운송장이 있는 주문이면 **[대체하기]** 확인창이 뜨고, 기존 운송장은 중복이 됩니다.
> 미매칭 사유는 표에 나옵니다. "해당 공급처 배정 없음"이면 공급처를 잘못 골랐을 수 있으니 운송장을 삭제하고 맞는 공급처로 다시 올리세요.

#### 플랫폼 파일 다운로드

**플랫폼 파일 다운로드** 탭을 클릭합니다.

쿠팡과 토스 카드가 각각 표시됩니다.

**다운로드 방법:**
- **파일이 1개일 때**: 카드의 **[엑셀 다운로드]** 클릭
- **파일이 2개 이상일 때**: **[쿠팡1]**, **[쿠팡2]** 버튼으로 하나씩, 또는 카드의 **[전체 다운로드]**로 파일별 각각 받기
- **양식 미등록**: 플랫폼 운송장 양식이 없으면 다운로드가 비활성입니다. 설정의 운송장 양식에서 등록하세요.

> **미매칭 경고**: 미매칭 건이 있으면 노란색 경고 배너가 뜹니다. 미매칭 건은 운송장 파일에 포함되지 않으니 매칭을 먼저 처리하세요.

다운로드한 파일을 **쿠팡 셀러 / 토스 셀러 페이지**에서 업로드합니다.

#### 가격정리에 운송장 붙여넣기

플랫폼 다운로드 카드 아래 **가격정리에 운송장 붙여넣기**에서 가격정리 파일에 택배사와 운송장번호를 채웁니다.

1. 목록의 **[미리보기]**에서 행 번호와 주문번호를 확인합니다.
2. **[복사]**를 누릅니다.
3. 가격정리 파일의 **A3** 칸을 선택하고 붙여 넣습니다.

택배사는 플랫폼 표기로 들어가고, 운송장이 없는 주문은 빈 줄로 남습니다. 가격정리 파일을 정렬했거나 행을 지웠거나, 파일을 받은 뒤 주문을 추가했다면 행이 어긋날 수 있으니 첫 주문번호와 마지막 주문번호가 같은지 확인하세요. 붙여 넣으면 직접 입력한 칸도 덮어써지고, 운송장 없는 줄은 비워집니다.

#### 운송장 처리 완료

모든 운송장 파일을 다운로드하고 플랫폼에 업로드했으면:

1. **[운송장 처리 완료]** 클릭
2. "플랫폼 업로드 파일을 다운로드했습니다"를 체크하고 **[완료하기]** 클릭
3. 작업건 상태가 **"완료"** 로 바뀝니다. 완료 후에는 업로드와 수동 매칭을 할 수 없습니다.

### 4-2. 간편 운송장

작업건 없이 빠르게 운송장을 처리하는 모드입니다.

**시작 방법:**
1. 사이드바에서 **운송장** 클릭
2. 화면 오른쪽 위의 **[간편 운송장]** 버튼 클릭

**Step 1 — 주문 업로드:**
- 쿠팡/토스 주문 엑셀 파일을 업로드합니다
- 파일별로 읽은 건수가 표시됩니다

**Step 2 — 운송장 업로드:**
- 공급처를 선택하고 운송장 엑셀을 업로드합니다
- 올리는 즉시 주문과 자동 매칭됩니다
- 파일 행의 상세 보기를 펼쳐 결과를 확인합니다
- 여러 공급처의 운송장을 순서대로 올릴 수 있습니다

**Step 3 — 결과 확인:**
- 표에서 전체/매칭/미매칭으로 거르고 쿠팡/토스 플랫폼 파일을 다운로드합니다
- 간편 운송장의 **[전체 다운로드]**는 합쳐진 파일 1개로 받습니다
- 수동 매칭이 안 되므로 미매칭은 파일에서 빠집니다
- 주문번호 없는 운송장 경고와 가격정리 붙여넣기도 없습니다

> **주의**: 간편 운송장은 **저장되지 않습니다**. 페이지를 벗어나면 데이터가 사라집니다.
> 반드시 파일을 다운로드한 후 페이지를 나가세요.

## 5. 매핑관리 — 공급처 관리

사이드바 **매핑관리** → 왼쪽 탭에서 **공급처 관리** 클릭

**"공급처"란?** 과일을 납품받는 거래처(농장, 도매 등)입니다.

### 공급처 추가하기

1. **[공급처 추가]** 클릭
2. 입력창이 뜹니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **공급처 이름** | 거래처 이름 | 필수 | `A농장` |
| **연락처** | 전화번호나 담당자 | 선택 | `010-1234-5678 김사장님` |
| **메모** | 참고할 내용 | 선택 | `사과 전문, 화요일 배송불가` |

3. **[공급처 추가]** 클릭 → 공급처 상세 페이지로 이동합니다

### 공급처 수정하기

1. 수정할 공급처 행의 연필 아이콘 클릭
2. 내용 수정 후 **[수정 저장]** 클릭

### 공급처 상세 페이지

공급처 행을 **클릭**하면 상세 페이지로 이동합니다. 여기서:

- **기본 정보 수정**: 이름, 연락처, 메모
- **발주서 양식**: 이 공급처에 보낼 발주서 엑셀 양식 설정 (→ 10장 참고)
- **상품 목록**: 이 공급처의 상품과 가격, 재고 관리
- **운송장 양식**: 이 공급처가 보내는 운송장 파일의 칸 지정

### 상품 목록 올리기

1. 상품 목록의 **[양식 설정]** 클릭 → 공급처 상품 엑셀 파일 선택
2. 칸 지정 (상품명 필수) 후 저장하면 상품까지 함께 올라갑니다
3. 이후에는 공급처 상세의 **[상품 업로드]**, 공급처 관리 목록의 업로드 아이콘, 공급처 배정의 **[상품 목록 갱신]** 중 한 곳에서 파일을 올립니다

> 공급처 파일의 열 순서가 바뀌면 상품 목록의 **[양식 재설정]**을 누르고 새 파일을 고릅니다. 열 지정이 모두 초기화되니 상품명, 옵션명, 가격 열을 다시 지정하고 저장하세요. 열 위치로 읽기 때문에 그대로 올리면 가격이 비거나 다른 숫자가 가격으로 들어갈 수 있습니다. 이미 배정된 주문의 가격은 바뀌지 않습니다.

> 주의: 상품 파일을 올리면 기존 상품 목록이 **전체 교체**됩니다. **[양식 삭제]**를 누르면 상품 데이터도 함께 삭제됩니다.

> **상품 목록을 올리면 뭐가 좋나요?**
> - 자동 배정 시 **가격, 재고** 정보를 참고합니다
> - 배정 페이지에 **공급처 가격**이 표시됩니다
> - 품목 검토에서 **최저가 추천**이 가능해집니다

### 공급처별 운송장 양식

공급처마다 운송장 파일 모양이 다르면 공급처 상세의 **운송장 양식**에서 **[양식 등록]**을 누르고 샘플 파일을 올립니다. 칸마다 매칭번호, 운송장번호, 택배사, 상품명, 수령인을 지정합니다. 매칭번호와 운송장번호는 필수이고, 택배사 칸이 없으면 기본 택배사를 적습니다. 쿠팡/토스용 운송장 양식(11장)과는 다른 설정입니다.

### 공급처 비활성화 / 활성화 / 삭제

| 동작 | 어떻게? | 뭐가 되나요? |
|------|---------|-------------|
| **비활성화** | 공급처 행의 전원 아이콘 → 확인창의 **[비활성화]** | 자동 배정에서 제외됩니다. 품목 매핑이 남아 있어도 배정되지 않습니다. 기존 데이터는 유지됩니다. |
| **활성화** | 비활성 뱃지가 붙은 행의 되돌리기 아이콘 클릭 | 다시 배정 대상에 포함됩니다. |
| **완전삭제** | 공급처 행의 🗑️ 클릭 | 공급처와 매핑, 상품, 양식이 삭제됩니다. 되돌릴 수 없습니다. 배정이나 운송장 이력이 있으면 삭제할 수 없습니다. |

> 비활성 공급처는 같은 표에 "비활성" 뱃지로 표시됩니다.

## 6. 매핑관리 — 품목 매핑

사이드바 **매핑관리** → 왼쪽 탭에서 **품목 매핑** 클릭

**"품목 매핑"이 뭔가요?**
"이 상품은 이 공급처로 보내라"는 규칙입니다. 예를 들어:

```
"산지직송 성주 꿀참외" (쿠팡) → A농장
"참외 5kg 특상품"       (토스) → A농장
"프리미엄 사과 세트"     (공통) → B농장
```

이 규칙이 있으면, 주문이 들어올 때 시스템이 자동으로 맞는 공급처에 배정합니다.

### 품목 매핑이 만들어지는 2가지 방법

**방법 1 — 자동 등록 (가장 편함):**
- 공급처 배정 페이지에서 "미분류" 주문에 공급처를 지정하면
- 그 상품명+공급처가 **자동으로 품목 매핑에 등록**됩니다
- 다음에 같은 상품이 오면 자동 배정됩니다

**방법 2 — 수동 등록:**
- 품목 매핑 페이지에서 직접 추가합니다 (아래 참고)

공급처 배정의 추천을 적용해도 매핑이 저장됩니다.

### 수동으로 품목 매핑 추가하기

1. **[매핑 추가]** 클릭
2. 옆 패널에 입력합니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **플랫폼** | 쿠팡/토스/공통 중 선택. 같은 상품에 쿠팡 전용 매핑이 있으면 쿠팡 주문에는 공통 매핑을 쓰지 않음(토스도 같음) | 필수 | `공통` |
| **상품명** | 플랫폼에서 들어오는 등록상품명 | 필수 | `산지직송 성주 꿀참외` |
| **옵션명** | 플랫폼 옵션명. 비워두면 상품명이 같은 주문의 모든 옵션에 적용됨. 옵션까지 같은 매핑이 따로 있으면 그쪽을 먼저 씀 | 선택 | `1박스 특가혼합과 5kg` |
| **공급처** | 이 상품을 보낼 공급처 선택 | 필수 | `A농장` |
| **우선순위** | 숫자 (0~999), 작을수록 먼저. 기본 매핑이 여러 개이거나 가격이 같은 후보가 있을 때만 쓰임 | 선택 | `0` |
| **기본 매핑으로 설정** | 체크하면 이 공급처가 기본 배정 대상. 처음부터 체크되어 있음 | 선택 | ☑ |

3. **[매핑 추가]** 클릭 (수정할 때는 **[수정 저장]**)

> **"상품명"은 정확히 뭘 넣어야 하나요?**
> 쿠팡이면 "등록상품명" (쿠팡 셀러에서 보이는 상품명), 토스면 "상품명"입니다.
> 주문 업로드 후 배정 페이지에서 보이는 상품명을 그대로 복사해서 넣으면 됩니다.

> **"옵션명"을 비워두면?**
> 상품명 전체가 같은 주문의 모든 옵션에 적용됩니다.
> 예: "사과"에 옵션을 비우면 상품명이 "사과"인 주문의 3kg, 5kg 옵션에 모두 적용되지만, 상품명이 "사과 3kg"인 주문에는 적용되지 않습니다.

> **글자가 완전히 같아야 하나요?**
> 이모지, ☆◆ 같은 기호, 대괄호와 그 안의 글자(예: [특가]), 특수문자, 겹친 띄어쓰기, 영문 대소문자 차이는 무시하고 비교합니다. 소괄호는 괄호만 빼고 안의 글자는 비교합니다.

> **같은 상품에 여러 공급처를 넣을 수 있나요?**
> 네, 가능합니다. 기본 공급처가 품절이 아니면 기본 공급처로 배정합니다. 기본 공급처가 품절이거나 기본이 없으면 품절이 아닌 후보 중 상품 목록 가격이 가장 싼 곳으로 배정하고, 가격이 같거나 없으면 기본 매핑을 먼저, 그다음 우선순위가 작은 곳을 씁니다.
> 공급처 상품 목록이 전혀 없으면 기본 매핑 중 우선순위가 가장 작은 곳(기본이 없으면 전체 중)으로 배정합니다.

### 품목 매핑 수정/삭제

- **수정**: 행의 연필 아이콘 클릭 → 수정 → [수정 저장]
- **삭제**: 행의 🗑️ 아이콘 클릭 → 확인 → 삭제됨

### 미매핑 품목 감지

상단 **[미매핑 품목 감지]**를 누르면 최근 주문 2,000건 중 매핑 없는 품목이 나옵니다. 공급처를 고르고 **[N건 일괄 등록]**을 누르면 기본 매핑으로 저장됩니다.

## 7. 매핑관리 — 상품명 변환

사이드바 **매핑관리** → 왼쪽 탭에서 **상품명 변환** 클릭

**"상품명 변환"이 뭔가요?**
플랫폼에 있는 상품명을 공급처가 알아보는 이름으로 바꿔주는 규칙입니다.

예시:
| 플랫폼 상품명 | → | 공급처 발주서에 표시되는 이름 |
|-------------|---|---------------------------|
| 프리미엄 산지직송 사과 세트 3kg | → | 사과 3kg |
| [특가] 성주 꿀참외 혼합과 5kg | → | 참외 혼합 5kg |

**품목 매핑과 뭐가 다른가요?**
- **품목 매핑**: "이 상품 → 이 공급처로 보내라" (배정 규칙)
- **상품명 변환**: "이 상품명 → 발주서에 이 이름으로 써라" (이름 변환 규칙)

### 상품명 변환 추가하기

1. **[매핑 추가]** 클릭
2. 입력합니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **플랫폼** | 쿠팡/토스/공통 중 선택 | 필수 | `공통` |
| **플랫폼 상품명** | 플랫폼에서 들어오는 상품명 (정확히) | 필수 | `산지직송 성주 꿀참외` |
| **플랫폼 옵션명** | 옵션까지 정확히 같아야 적용. 비우면 옵션이 없는 주문에만 적용 | 선택 | `1박스 특가혼합과 5kg` |
| **공급처** | 이 변환을 적용할 공급처 선택 | 필수 | `A농장` |
| **공급처 상품명** | 발주서에 적힐 이름 | 필수 | `정품 참외 중소과 5kg` |
| **공급처 상품코드** | 공급처 자체 상품 코드가 있으면 입력 | 선택 | `PIDY82D` |

3. **[매핑 추가]** 클릭 (수정할 때는 **[수정 저장]**)

> **공급처 상품명 칸에 뭘 넣어야 하나요?**
> 공급처 발주서에 적어야 하는 상품 이름입니다. 공급처에서 "이 이름으로 보내주세요"라고 한 이름을 넣으면 됩니다.

### 자동 매칭 제안

상단 **[자동 매칭 제안]**을 누르면 상품명 변환이 없는 품목 매핑에 대해 비슷한 공급처 상품을 찾아 줍니다. 맞는 항목만 체크하고 **[N건 등록]**을 누르세요. 50% 이상 비슷한 항목은 미리 체크되어 있습니다.

> 공급처를 먼저 고르면 공급처 상품명 칸을 눌렀을 때 상품 목록이 나옵니다. 선택하면 상품코드도 채워집니다.
> 상품명 변환은 배정할 때 적용되므로, 이미 배정된 주문에는 반영되지 않습니다.

## 8. 매핑관리 — 택배사 매핑

사이드바 **매핑관리** → 왼쪽 탭에서 **택배사 매핑** 클릭

**"택배사 매핑"이 뭔가요?**
운송장에 적힌 택배사 이름을 쿠팡/토스가 인식하는 정식 명칭으로 변환합니다. **모든 공급처에 공통 적용**됩니다.

예시:
| 운송장에 적힌 이름 | → 쿠팡에 올릴 이름 | → 토스에 올릴 이름 |
|------------------|------------------|------------------|
| 대한통운 | CJ 대한통운 | CJ대한통운 |
| 로젠 | 로젠택배 | 로젠택배 |

### 택배사 매핑 추가하기

1. **[매핑 추가]** 클릭
2. 입력합니다:

| 칸 | 뭘 입력하나요? | 필수? | 예시 |
|----|--------------|------|------|
| **원본 택배사명** | 운송장에 적혀있는 택배사명 (정확히) | 필수 | `대한통운` |
| **쿠팡 택배사명** | 쿠팡에 업로드할 때 넣을 이름 | 필수 | `CJ 대한통운` |
| **토스 택배사명** | 토스에 업로드할 때 넣을 이름 | 필수 | `CJ대한통운` |

3. **[매핑 추가]** 클릭 (수정할 때는 **[수정 저장]**)

> **택배사 매핑이 없으면?**
> 운송장에 적힌 이름이 그대로 쿠팡/토스에 들어갑니다. 이름이 안 맞으면 플랫폼에서 오류가 날 수 있으니 등록해두는 게 좋습니다.

> 한 번 등록하면 어떤 공급처의 운송장이든 동일하게 적용됩니다. 원본 택배사명은 전체에서 하나만 등록할 수 있습니다. 수정과 삭제는 표의 각 행에서 합니다.

## 9. 매핑관리 — 과일 사전

사이드바 **매핑관리** → 왼쪽 탭에서 **과일 사전** 클릭

**"과일 사전"이 뭔가요?**
주문 상품명과 공급처 상품명을 이어 주는 **단어장**입니다. 시스템은 뜻을 이해하지 못하고 글자만 비교하기 때문에, 어떤 단어가 어떤 과일이고 어떤 크기인지 여기에 적어 줘야 합니다.

**언제 쓰나요?**

공급처 상품을 자동으로 찾으려면 사전 등록이 필요합니다. 사전이 없는 과일은 품목 검토에서 묶일 수는 있어도 공급처 상품명과 가격이 자동으로 들어가지 않습니다.

- 새로운 과일을 팔기 시작할 때
- 공급처 배정에서 가격 미확인이 뜨고 사유가 상품을 찾지 못한 경우일 때
- 품목 검토에서 같은 과일이 여러 그룹으로 쪼개질 때
- 공급처에 없는 중량으로 주문이 들어올 때

**어떻게 작동하나요?**

상품명과 옵션에서 과일, 중량, 크기를 찾고, 공급처 상품명도 같은 방식으로 읽어서 가장 많이 일치하는 상품을 고릅니다.

```
주문: 제주 타이백 감귤 / 1박스, 2kg, 중대
과일: 키워드 "감귤" → 감귤
중량: 2kg → 무게 변환 → 3kg
크기: 크기 동의어 "중대" → 대과
결과: 제주 감귤 3Kg 대과
```

- 옵션을 상품명보다 먼저 봅니다. 손님이 실제로 고른 내용이기 때문입니다.
- 감귤 주문에 크기가 없으면 대과로 봅니다.
- 후보가 똑같이 일치하면 고르지 않고 가격 미확인으로 남깁니다. 직접 선택해 주세요.

### 과일 사전 추가하기

1. 오른쪽 위 **[추가]** 클릭
2. 입력 팝업이 뜹니다. 하나씩 설명합니다:

#### ① 카테고리 (과일명)

이 사전의 **대분류 이름**입니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **카테고리** | 과일 대표 이름 1개 | `사과` |

#### ② 키워드

이 과일에 해당하는 **모든 이름**을 쉼표로 구분해서 입력합니다.
상품명에 이 키워드 중 하나라도 있으면 이 카테고리로 분류됩니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **키워드** | 이 과일의 모든 이름, 쉼표 구분 | `사과, 부사, 홍로, 시나노골드, 아오리, 감홍` |

**이게 왜 필요한가요?**
- 플랫폼에 "부사 3kg"라고 올라오면, 키워드에 "부사"가 있으니까 → "사과"로 인식
- "홍로 5kg"도 → "사과"로 인식
- 품목 검토에서 "부사 3kg"과 "사과 5kg"이 **같은 "사과" 그룹**으로 묶여서 표시됨

**어떤 키워드를 넣어야 하나요?**
- 카테고리 이름 자체: `사과`
- 품종 이름: `부사`, `홍로`, `시나노골드`, `아오리`
- 지역명이 붙은 과일 이름: `영주사과` 등
- 플랫폼 상품명에 나올 수 있는 표현을 넣으세요

> 주의: 글자가 들어 있기만 하면 잡히므로, 다른 단어에 섞이는 한 글자는 넣지 마세요. `감`은 감귤과 감홍사과에, `배`는 배송에, `무`는 무료에 걸립니다. `단감`, `햇배`처럼 두 글자 이상으로 넣으세요. `제주`, `서귀포` 같은 지역명만 넣으면 다른 과일이 이 과일로 잡힐 수 있습니다.

#### ③ 등급 동의어 (선택)

같은 등급을 다르게 부르는 경우의 동의어입니다. **[+ 추가]** 버튼으로 그룹을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **대표명** | 등급의 표준 이름 | `특상` |
| **동의어** | 같은 뜻의 다른 표현, 쉼표 구분 | `프리미엄, 최상급, 특대, 특` |

예시: 여러 그룹을 추가할 수 있습니다
```
대표명: 특상    동의어: 프리미엄, 최상급, 특대
대표명: 상      동의어: 일반, 보통, 가정용
대표명: 중      동의어: 알뜰, 못난이
```

**이게 왜 필요한가요?**
- "프리미엄 사과 5kg"과 "특상 사과 5kg"가 있으면 → 둘 다 "특상" 등급으로 통일
- 표현이 달라도 같은 등급으로 인식해 공급처 상품을 찾습니다

#### ④ 크기 동의어 (선택)

같은 크기를 다르게 부르는 경우의 동의어입니다. **[+ 추가]** 버튼으로 그룹을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **대표명** | 크기의 표준 이름 | `대과` |
| **동의어** | 같은 뜻의 다른 표현, 쉼표 구분 | `중대, 중대과, 혼합과, m-l` |

예시:
```
대표명: 대과      동의어: 중대, 중대과, 혼합과, m-l
대표명: 로얄과    동의어: 로얄, 로열, 꼬마, s-m
```

대표명은 공급처 상품명에 쓰인 말로 맞추세요. 공급처 상품이 "제주 감귤 5Kg 대과"라면 대표명도 `대과`로 씁니다. 공급처 상품명에 쓰인 과일 이름도 키워드에 있어야 합니다.

같은 표현을 두 묶음에 넣으면 위쪽 묶음으로만 잡히니 한 곳에만 넣으세요.

#### ⑤ 무게 변환 (선택)

플랫폼 주문 무게를 공급처 발주 무게로 변환하는 규칙입니다. **[+ 추가]** 버튼으로 규칙을 추가합니다.

| 칸 | 뭘 입력? | 예시 |
|----|---------|------|
| **원본** | 플랫폼 상품명에 적힌 무게 | `4.5kg` |
| **변환** | 공급처에 발주할 때 쓸 무게 | `5kg` |

예시: 여러 규칙을 추가할 수 있습니다
```
4.5kg → 5kg
2kg   → 3kg
1.5kg → 2kg
```

**이게 왜 필요한가요?**
- 쿠팡에 "사과 4.5kg"로 올렸는데, 공급처에는 4.5kg 규격이 없고 5kg만 있을 때
- 이 규칙으로 공급처의 5kg 상품을 찾습니다
- 찾으면 그 상품명이 발주서에 나가고, 못 찾으면 플랫폼 이름 그대로 나갑니다
- 숫자와 소문자 kg을 붙여서 적고, 공급처에 실제로 있는 중량으로 적으세요
- 공급처에 3kg 상품이 있는데 `3kg → 5kg` 규칙을 넣으면 3kg 주문이 5kg 상품으로 나갑니다

3. 모든 입력이 끝나면 **[추가]** 클릭

### 안 잡히는 표현 추가하기

1. 과일 카드의 연필 아이콘 클릭
2. 주문 옵션에 있는 표현을 알맞은 동의어 칸에 넣음
3. **[수정]** 클릭

예: 옵션의 "꼬마"가 크기로 잡히지 않으면 감귤의 크기 동의어 `로얄과`에 `꼬마`를 넣습니다.

### 과일 사전 수정/삭제

- **수정**: 사전 카드의 연필 아이콘 클릭 → 수정 → [수정]
- **비활성화**: 사전 카드의 휴지통 아이콘 → 비활성 목록으로 이동 (데이터는 유지)
- **활성화 복원**: 비활성 목록에서 되돌리기 아이콘
- **완전삭제**: 비활성 목록에서 🗑️ 클릭 → 완전히 삭제됨. 되돌릴 수 없으니 먼저 비활성으로 두는 것을 권장

사전을 고치면 새로 배정하는 주문부터 적용됩니다. 이미 배정된 주문은 공급처 배정 화면에서 파란색 발주 상품명을 눌러 다시 고르세요. [재배정]은 작업건 전체를 다시 배정해서 손으로 바꾼 내용도 사라집니다.

> 주의: 가격이 들어갔다고 항상 맞는 상품은 아닙니다. 상품명에 "로얄"이 있고 옵션에 크기가 없으면 로얄과로 잡힐 수 있습니다. 크기가 중요한 주문은 발주서를 보내기 전에 한 번 확인하세요.

### 과일 사전 예시 — 감귤류

실제로 이렇게 등록할 수 있습니다:

```
카테고리: 감귤
키워드: 감귤, 귤, 밀감
크기 동의어:
  - 대표명: 대과 / 동의어: 중대, 혼합과
  - 대표명: 로얄과 / 동의어: 로얄, 로열, 꼬마
무게 변환:
  - 2kg → 3kg
  - 4.5kg → 5kg
  - 9kg → 10kg
```

이 사전이 있으면:
- "귤 2kg 중대" → 감귤, 3kg, 대과
- "밀감 4.5kg 로열" → 감귤, 5kg, 로얄과
- 품목 검토에서 "귤"과 "밀감"이 같은 "감귤" 그룹으로 묶임

## 10. 공급처 상세 — 발주서 양식

**발주서 양식이 뭔가요?**
공급처마다 발주서 엑셀 양식이 다릅니다. A농장은 "받는분, 연락처, 상품, 수량" 순서이고, B농장은 "주문번호, 상품코드, 수량, 이름, 주소" 순서일 수 있습니다. 양식을 등록해두면 시스템이 각 공급처 양식에 맞춰서 자동으로 발주서를 만들어줍니다.

### 발주서 양식 등록하기

1. 사이드바 **매핑관리** → **공급처 관리** → 공급처 클릭하여 **상세 페이지** 진입
2. **발주서 양식**의 **[양식 등록]** 클릭
3. **헤더 행 번호**: 헤더가 1행이 아니면 파일을 고르기 전에 먼저 입력합니다
4. **템플릿 파일(.xlsx)**: 공급처에서 받은 빈 발주서 양식을 선택합니다
5. **시트명**: 엑셀에 시트가 여러 개면 데이터가 들어갈 시트를 선택
6. **데이터 시작 행 번호**: 실제 데이터가 시작될 행 번호 (보통 2)
7. **컬럼 매핑**: 양식의 각 열에 **어떤 데이터를 넣을지** 지정합니다

### 컬럼 매핑 상세

양식의 각 열이 나열됩니다. 각 열의 드롭다운에서 넣을 데이터를 선택합니다. 매칭키, 수량, 수취인명, 수취인 연락처, 주소는 필수이고, 공급처 상품명과 플랫폼 상품명 중 하나도 필수입니다:

| 선택값 | 뭐가 들어가나요? |
|--------|-----------------|
| **매칭키 (배송/상품번호)** | 쿠팡: 묶음배송번호:옵션ID, 토스: 주문상품번호 |
| **주문번호** | 플랫폼 주문번호 |
| **주문상품번호** | 주문 내 상품번호 |
| **공급처 상품명** | 상품 목록에서 찾은 상품명 또는 상품명 변환 이름. 둘 다 없으면 플랫폼 노출 상품명 |
| **플랫폼 상품명** | 쿠팡=노출상품명(옵션명), 토스=상품명+옵션명 |
| **공급처 상품코드** | 상품 목록 또는 상품명 변환의 코드 |
| **수량** | 주문 수량 |
| **수취인명** | 받는 사람 이름 |
| **수취인 연락처** | 받는 사람 전화번호 |
| **우편번호** | 우편번호 |
| **주소** | 배송 주소 |
| **배송메시지** | 배송 시 요청사항 |
| **주문자명** | 주문한 사람 이름 |
| **주문자 연락처** | 주문한 사람 전화번호 |
| **주문일시** | 주문 날짜/시간 |
| **보내는분 주소** | 수취인 주소와 동일 |
| **빈 칸** | 아무것도 안 넣음 |

**전화번호 형식**: 수취인/주문자 연락처를 선택하면 형식을 추가로 지정합니다:
- **원본**: 플랫폼에서 받은 그대로 (예: 010-1234-5678)
- **하이픈**: 하이픈 형식 (예: 010-1234-5678)
- **숫자만**: 숫자만 (예: 01012345678)

8. **[저장]** 클릭

> **"공급처 상품명"과 "플랫폼 상품명" 차이가 뭔가요?**
> - **공급처 상품명**: 상품 목록 또는 상품명 변환의 이름. 공급처가 알아보는 이름.
>   예: "사과 3kg", "참외 혼합 5kg"
> - **플랫폼 상품명**: 쿠팡/토스에 올라가 있는 원본 이름.
>   예: "프리미엄 산지직송 사과 세트 3kg", "[특가] 성주 꿀참외 혼합과 5kg"
> - 공급처가 "원본 상품명 그대로 보내줘"라고 하면 → **플랫폼 상품명** 선택
> - 공급처가 "우리 상품코드/이름으로 보내줘"라고 하면 → **공급처 상품명** 선택

## 11. 설정 — 운송장 양식

사이드바 설정의 **운송장 양식** 클릭

**운송장 양식이 뭔가요?**
쿠팡/토스 셀러 페이지에서 운송장을 일괄 등록할 때 사용하는 엑셀 양식 파일입니다. 시스템이 이 양식에 택배사명과 운송장번호를 자동으로 채워줍니다.

### 운송장 양식 등록하기

1. 상단 **쿠팡/토스** 탭 선택
2. **[양식 등록]** 또는 **[양식 변경]** 클릭
3. 셀러 페이지에서 받은 양식 파일(.xlsx) 업로드
4. **[다음]**으로 시트 선택, 헤더 행 번호, 데이터 시작 행 번호 확인
5. 컬럼 매핑을 드롭다운으로 선택:

| 설정 | 뭔가요? | 예시 |
|------|---------|------|
| **매칭키 컬럼** | 플랫폼 매칭번호가 있는 열 | 쿠팡: 묶음배송번호 관련 열 |
| **택배사 컬럼** | 택배사명을 채울 열 | 쿠팡: D열(4) |
| **운송장번호 컬럼** | 운송장번호를 채울 열 | 쿠팡: E열(5) |
| **주문상태 컬럼** (토스만) | "배송중"을 채울 열 | 토스: D열(4) |
| **주문상태 변경값** (토스만) | 채울 텍스트 | `배송중` |

6. 미리보기 확인 후 **[저장]** 클릭

> 같은 열은 중복으로 고를 수 없고, 토스는 주문상태 컬럼이 필수입니다.
> 플랫폼이 양식을 변경했을 때는 **[양식 변경]**으로 새 파일을 올리고 컬럼 위치를 확인하세요.

## 13. 자주 묻는 질문 (FAQ)

### 새 품목이 나왔을 때 어떻게 하나요?

공급처 배정 페이지에서 **"미분류"** 또는 **"추천"** 행으로 표시됩니다.
공급처를 선택하고 적용하면 → 품목 매핑에 등록됨 → 다음부터는 자동 배정됩니다.

### 공급처를 오늘만 바꾸고 싶어요

배정 페이지에서 공급처 드롭다운 클릭 → 새 공급처 선택 → **[오늘만 적용]**.
다음 작업건은 원래 공급처로 자동 배정됩니다.

### 공급처를 영구적으로 바꾸고 싶어요

배정 페이지에서 공급처 드롭다운 클릭 → 새 공급처 선택 → **[기본 매핑도 변경]**.
품목 검토의 "기본 저장"은 추천 표시만 바꾸고 자동 배정에는 쓰이지 않습니다.

### 운송장이 매칭 안 돼요

사유 칸을 먼저 확인하세요.
- 매칭 결과에서 **"미매칭"** 행의 **[수동 매칭]** 클릭
- 주문 목록에서 주문을 찾아 **[연결]** 클릭
- "해당 공급처 배정 없음"이면 공급처를 잘못 골랐을 수 있습니다. 운송장을 삭제하고 맞는 공급처로 다시 올리세요

### 토스 엑셀이 안 올라가요

토스 엑셀은 **원본 파일을 수정 없이 그대로** 올려야 합니다.
시트 이름(주문내역)을 바꾸거나 주문일시, 주문번호, 주문상품번호 열 제목을 지우면 읽지 못합니다.

### 쿠팡 파일이 여러 개예요

두 번째 파일 업로드 시 **[별도 파일]**을 선택하면 "쿠팡1", "쿠팡2"로 따로 관리됩니다. 운송장 다운로드도 각각 분리되어 나옵니다.

### 과일 사전 꼭 등록해야 하나요?

네. 사전이 없는 과일은 품목 검토에서 묶일 수는 있어도 공급처 상품명과 가격이 자동으로 들어가지 않습니다. 새 과일을 팔기 시작하면 먼저 등록하세요.

### 공급처는 배정됐는데 가격 미확인이 떠요

공급처 상품을 찾지 못했거나 상품 목록에 가격이 없는 경우입니다. 뱃지에 마우스를 올려 사유를 보고, 파란색 발주 상품명을 눌러 상품을 고르세요. 이미 배정된 주문은 사전을 고쳐도 자동으로 바뀌지 않습니다.

### 플랫폼 운송장 파일에 주문이 몇 건 없어요

플랫폼 파일에는 운송장이 있는 주문만 들어갑니다. 3단계의 **가격정리에 운송장 붙여넣기**에서 운송장이 없는 주문 건수를 확인하고, 공급처 파일에 그 주문이 있는지 보세요.

### 간편 운송장은 뭔가요?

작업건 없이 주문 파일과 운송장 파일만 넣으면 바로 매칭해주는 빠른 모드입니다.
운송장 페이지 오른쪽 위 **[간편 운송장]** 버튼으로 시작합니다.
다만 저장되지 않으므로, 페이지를 나가면 데이터가 사라집니다.

### 발주 완료 후 수정하고 싶어요

발주서 다운로드 페이지의 **[발주 되돌리기]** → **[되돌리기]** → "진행중"으로 돌아감 → 수정 가능.

### 운송장 파일을 잘못 다운로드했어요

같은 페이지에서 다시 다운로드하면 됩니다. 횟수 제한 없습니다.

### "작업건"이 정확히 뭔가요?

발주 한 번을 묶는 단위입니다.
그때 올린 주문, 배정, 발주서, 운송장이 이 작업건 안에 관리됩니다.
과거 작업건도 목록에서 확인할 수 있어서, "5월 12일에 A농장에 뭘 보냈지?" 같은 이력 확인이 가능합니다.

### 보내는분 정보는 어떻게 되나요?

발주서의 "보내는분" 관련 칸은 항상 비어있거나 수취인 주소가 들어갑니다.
실제 발신자 정보는 공급처에서 직접 관리합니다.
