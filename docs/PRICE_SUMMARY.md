# 가격정리 다운로드

4단계에서 발주 완료 여부와 관계없이 원본 주문 목록별 가격정리를 받는다. 공급처 단가는 배정 당시 저장된 값이며 다운로드가 배정을 수정하지 않는다. 배정·가격 누락은 화면에서 알리고 사용자 확인 시 해당 금액을 빈칸으로 출력한다.

- 택배사(A열)는 원본에 값이 있어도 빈칸으로 출력한다. 송장번호는 기존대로 원본 값을 사용한다.
- A~M만 채우고 N열 이후의 값·수식은 보존한다. 마진금액(P열)은 음수일 때만 빨간 글씨가 되는 조건부 서식을 추가한다.
- 실제 주문은 3행부터, 2행 A~M 예시는 제거한다.
- 구매가격은 저장 단가 × 수량, 판매금액은 원본 결제액/주문금액이다.
- 정산 수식은 3,107행까지 있으므로 3,105건을 넘으면 경고한다. 수식을 자동 확장하지 않는다.
- 파일명은 최초 원본 이름 + `_가격정리.xlsx`. 추가 주문은 기존 목록에 합친다.
- 택배사(A열)와 송장번호(B열)는 다운로드 파일에 채우지 않는다. 운송장 매칭 후 운송장 3단계에서 복사해 A3에 붙여 넣는다.
- 운송장 후속 재다운로드와 Google Sheets API는 포함하지 않는다.

## 배포 순서

1. `supabase/migrations/20261030_price_summary_original_filename.sql`을 대상 DB에 적용한다.
2. 다음 조회로 과거 병합 파일 중 최초 이름 확인이 필요한 기록을 확인한다. 검증한 최초 파일명으로 `original_file_name`만 채운다. 임의로 문자열을 잘라 복원하지 않는다.

```sql
select id, file_name, label from public.order_imports where original_file_name is null;
```

3. 서버용 환경에서 `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`를 설정하고 `node scripts/upload-price-template.mjs`를 실행한다. 키를 VITE 변수나 저장소에 넣지 않는다. 공통 양식은 `templates` 버킷의 `price-summary/v1.xlsx`에 등록된다.
4. 프런트엔드를 배포한다. 마이그레이션 또는 템플릿이 누락되면 오류 안내하며 파일을 생성하지 않는다.
5. 실제 계정으로 완료 전·후 다운로드, 누락 경고와 빈칸 출력, 같은 이름 목록 분리를 확인한다.

## 검증

자동 테스트는 익명 데이터로 금액 변환·목록 분리·XML 셀 보존·3,800건 출력을 검증한다. 쿠팡/토스 원본 샘플은 개인정보 때문에 저장소에 포함하지 않는다. `templates/price-summary-v1.xlsx`는 제공된 예시 전용 공통 양식이다.

Excel에서 열기·수식 재계산과 실제 인증 계정의 화면 확인은 배포 환경 검증 항목이다. 자동 재계산 요청을 파일에 기록하지만 SheetJS 읽기 테스트만으로 Excel 재계산 성공을 보장하지 않는다.
