# REF: 엑셀 파일 구조

> 실제 샘플 파일 분석 결과. 파서 구현 시 이 문서의 컬럼 인덱스/이름을 기준으로 작업.

## 1. 쿠팡 주문 엑셀

- **시트명**: `Delivery`
- **헤더**: 1행
- **데이터**: 2행~
- **행수**: 251 (헤더 포함) = 주문 250건
- **열수**: 40

### 파일 식별 조건
1행에 `번호`, `묶음배송번호`, `주문번호` 컬럼이 존재하면 쿠팡.

### 전체 컬럼 (40개, 0-indexed)
```
 0: 번호
 1: 묶음배송번호              ★ 옵션ID와 조합하여 orderItemNo, matchingKey
 2: 주문번호                  ★ orderNo
 3: 택배사
 4: 운송장번호
 5: 분리배송 Y/N
 6: 분리배송 출고예정일
 7: 주문시 출고예정일
 8: 출고일(발송일)
 9: 주문일                    ★ orderDate
10: 등록상품명                 ★ productName
11: 등록옵션명                 ★ optionName
12: 노출상품명(옵션명)          ★ displayProductName (발주서 품목명용)
13: 노출상품ID
14: 옵션ID                    ★ 묶음배송번호와 조합하여 상품 구분
15: 최초등록등록상품명/옵션명
16: 업체상품코드
17: 바코드
18: 결제액
19: 배송비구분
20: 배송비
21: 도서산간 추가배송비
22: 구매수(수량)              ★ quantity
23: 옵션판매가(판매단가)
24: 구매자                    ★ buyerName
25: 구매자전화번호             ★ buyerPhone
26: 수취인이름                 ★ recipientName
27: 수취인전화번호             ★ recipientPhone
28: 우편번호                   ★ zipCode
29: 수취인 주소               ★ address
30: 배송메세지                 ★ deliveryMessage
31: 상품별 추가메시지
32: 주문자 추가메시지
33: 배송완료일
34: 구매확정일자
35: 개인통관번호(PCCC)
36: 통관용수취인전화번호
37: 기타
38: 결제위치
39: 배송유형
```

### 실제 데이터 예시 (행2)
```
주문번호: "31100187326921"
주문일: "2026-04-29 09:01:45"
등록상품명: "산지직송 당도선별 석군참외 성주참외 5kg 실중량"
등록옵션명: "1박스 성주참외 가정용 혼합과 5KG"
구매수(수량): "1"
구매자: "최용훈"
구매자전화번호: "0504-3406-1054"  ← 안심번호, 하이픈 있음
수취인이름: "최용훈"
수취인전화번호: "0504-3406-1054"
우편번호: "04129"
수취인 주소: "서울특별시 마포구 아현동 777 마포 래미안 푸르지오 201동 ..."
배송메세지: "문 앞"
```

### 특이사항
- 전화번호에 하이픈 포함 (안심번호 0504-xxxx-xxxx, 0502-xxxx-xxxx)
- 한 주문번호에 여러 묶음배송번호가 존재할 수 있음
- 한 묶음배송번호에도 여러 옵션ID가 존재할 수 있어 주문 라인은 `묶음배송번호:옵션ID`로 구분
- 공급처 운송장은 발주서의 상품별 매칭키로 연결. 묶음배송번호만 있으면 후보가 하나일 때만 매칭
- 택배사/운송장번호 컬럼이 있지만 주문 엑셀에서는 비어있음

## 2. 토스 주문 엑셀

- **시트명**: `주문내역`
- **헤더 위치**: 동적 감지 (0~9행 스캔, 주문일시/주문번호/주문상품번호 마커 2개 이상)
- 일반적: 1행 그룹헤더, **2행 컬럼헤더**, 3행 수정가능여부, **4행~ 데이터**
- 2026-05-12~: 안내문구 1행 추가 → **3행 컬럼헤더**, **5행~ 데이터**
- **데이터 시작 = 헤더행 + 2**
- **열수**: 30

### 파일 식별 조건

```
 4: 발송기한

 6: 송장번호
 7: 상품ID
 8: 상품명                    ★ productName
 9: 상품 관리 코드
10: 옵션 ID
11: 옵션명                    ★ optionName
12: 주문건수                   ★ quantity
13: 옵션 관리 코드
14: 받은 혜택
15: 구매자명                   ★ buyerName
16: 구매자 연락처              ★ buyerPhone
17: 수령인명                   ★ recipientName
18: 수령인 연락처              ★ recipientPhone
```

### 실제 데이터 예시 (행5)
```

주문상태: "결제완료"

수령인명: "이한희"
```

### 특이사항
- 전화번호에 **하이픈 없음** (쿠팡과 다름)


### 실제 데이터 예시

- 263건 중 일부는 다른 날짜/플랫폼 주문 → 현재 작업건과 매칭 안 될 수 있음 (정상)
- 택배사 표기: "CJ대한통운" (공백 없음) — 쿠팡 정식명과 다를 수 있음

## 5. 쿠팡 운송장 업로드 양식

- **시트명**: `Delivery`
- **헤더**: 1행 (쿠팡 주문 엑셀과 동일한 40컬럼)
- **데이터**: 2행~
- **행수**: 14 (샘플에 데이터 13건 포함)
- **열수**: 40

### 핵심 컬럼 위치 (1-based index)
```
 3: 주문번호     → matchKeyColumnIndex
 4: 택배사       → trackingCompanyColumnIndex (비어있음 → 여기 채움)
 5: 운송장번호   → trackingNumberColumnIndex (비어있음 → 여기 채움)
```

### 출력 방식
1. 빈 양식 로드
2. 매칭된 주문의 `rawValues` 전체를 행에 복사 (원본 보존)
3. 4번(택배사), 5번(운송장번호) 컬럼만 덮어쓰기

## 6. 토스 운송장 업로드 양식

- **시트명**: `주문내역`
- **1~3행**: 그룹헤더 + 컬럼헤더 + 수정가능여부 → **보존**
- **4행~**: 데이터
- **행수**: 155 (데이터 152건)
- **열수**: 30

### 핵심 컬럼 위치 (1-based index)
```
 3: 주문상품번호  → matchKeyColumnIndex
 4: 주문상태      → statusColumnIndex (→ "배송중"으로 변경)
 6: 택배사        → trackingCompanyColumnIndex
 7: 송장번호      → trackingNumberColumnIndex
```

### 출력 방식
1. 빈 양식 로드 (1~3행 구조 보존)
2. 매칭된 주문의 `rawValues` 전체를 4행부터 복사
3. 4번(주문상태→"배송중"), 6번(택배사), 7번(송장번호) 덮어쓰기

## 9. 공급처 상품 목록

공급처마다 엑셀 양식이 다르므로, `supplier_product_templates` 테이블에 시트명·헤더행·데이터시작행·컬럼매핑을 저장하여 범용적으로 파싱한다.

### 매핑 대상 시스템 필드

| 필드명 | 설명 | 필수 |
|--------|------|------|
| `productCode` | 상품코드 | - |
| `productName` | 상품명 | **필수** |
| `optionName` | 옵션명 | - |
| `price` | 공급가(원) | - |
| `stockStatus` | 재고 상태 | - |
| `extra` | 기타 (매핑되지 않은 컬럼) | - |

### 재고 상태 정규화 규칙

| 원본값 | 변환 |
|--------|------|
| "판매중", "정상", "O", "Y", "있음" | `available` |
| "품절", "매진", "X", "N", "없음" | `soldout` |
| 양수 숫자 | `available` |
| 0 | `soldout` |
| 빈 값, "미정", 기타 | `unknown` |

### 가격 파싱 규칙
- 통화 기호 제거: ₩, ￦, 원 → 숫자만 추출
- 단위 제거: `/ 박스`, `/ 개` 등 → 슬래시 이후 버림
- 쉼표 제거: `15,000` → `15000`
- 음수/소수점 → `null` (가격 불명)
- 비숫자 텍스트("미정") → `null`

### 빈 행 처리 정책
- 모든 셀이 비어있음 → 건너뜀 (skippedRows)
- `productName`만 비어있고 다른 값 있음 → invalidRow (reason="상품명 누락")
- `productName` 있음 → 정상 파싱
