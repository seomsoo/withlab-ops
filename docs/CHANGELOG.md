# 사용자 요청 및 변경 이력

사용자가 요청한 기능 추가·수정과 실제 반영 내용을 기록한다. 최신 날짜를 위에 추가하고, **요청 → 반영 내용 → 상태 → 확인 사항** 순서로 작성한다. 후속 작업은 완료 항목과 구분하며 구현·배포·검증 상태를 혼동하지 않는다.

## 2026-11-02 — 가격정리 택배사 출력 변경

**요청:** 최초 가격정리 파일에는 원본 택배사를 가져오지 않아도 됨.

**반영 내용**

- 쿠팡·토스 모두 가격정리 엑셀의 택배사(A열)를 빈칸으로 출력한다.
- 택배사 열과 서식은 유지한다.
- 송장번호(B열)는 기존대로 업로드 원본에 값이 있으면 가져온다. 이후 매칭된 운송장을 가져오는 기능은 아직 포함하지 않는다.

**상태:** 코드 반영 완료. 관련 테스트 통과.

**확인 사항:** 주문일자를 더블클릭한 뒤 `####`로 보이는 현상은 기존 날짜·시간 서식 대비 열 너비가 좁아 발생할 수 있다. 사용자가 열 너비 조절로 대응하기로 하여 이번에는 날짜 서식·열 너비를 변경하지 않았다.

## 2026-10-29~30 — 원본 목록별 가격정리 다운로드

**요청:** 공급처 매칭이 끝난 주문을 기존 엑셀 양식에 맞춰 금액과 함께 확인하고, 쿠팡 계정별·토스 목록별로 각각 다운로드하고 싶음.

### 사용 중 발견한 오류와 수정

- **최초 파일명 열 조회 실패:** 화면에서 사용하는 `original_file_name` 열이 DB에 없어 발생. 연결된 DB에 마이그레이션과 최초 파일명 보존 트리거 적용, 기존 파일명 이관 및 공통 양식 등록 완료.
- **배정 응답 형식 오류:** 주문별 배정이 배열이 아닌 단일 객체로 반환되는 경우를 누락. 객체·배열·미배정 null을 공통 형식으로 변환하도록 수정하고 회귀 테스트 추가.
- **일부 배정 경로에서 단가 누락:** 상품명 매핑이 적용된 공급처 변경·수동 배정·분배 경로에서도 식별된 상품의 단가를 저장하도록 보완.

**상태:** 기능 구현 및 DB·Storage 설정 완료. 사용자가 결과 파일 다운로드 확인. 커밋·푸시와 서비스 배포 성공 여부는 Git/배포 이력에서 별도로 확인한다.

**검증:** 2026-11-02 기준 자동 테스트 283개, 타입 검사, 린트 통과. 생성 파일의 A~M 입력, 나머지 셀·수식 보존 및 3,800건 출력을 자동 검증했다. 실제 주문 전체 금액 대조 및 Excel 자체 재계산 검증을 모두 완료한 것은 아니다.

**제한:** 기존 정산 수식은 3,107행까지다. 3,105건을 초과하면 안내하며, A~M의 전체 주문은 출력하되 정산 수식을 자동 확장하지 않는다.

## 후속 작업 — 운송장 매칭 후 가격정리 재다운로드

**요청:** 발주 직후 가격정리는 먼저 받고, 나중에 운송장번호도 결과에 포함하고 싶음.

**상태:** 논의만 진행. 이번 구현에서 제외.

**논의한 방향:** 운송장 매칭 후 해당 주문의 택배사·송장번호를 넣어 가격정리 파일을 다시 다운로드한다. 기존 구매가격은 유지한다.

**다음 작업에서 확인할 사항:** 최초 파일을 사용자가 직접 편집하는지, 재다운로드 위치, 택배사 표기 기준, 일부 운송장만 매칭된 상태의 처리 방식. 로컬 엑셀 파일을 자동으로 갱신하는 기능으로 합의한 것은 아니다.
