엑셀 파서가 실제 샘플 파일을 올바르게 파싱하는지 검증해줘.

## 사전 조건
- `src/lib/parsers/` 아래에 파서 파일이 구현되어 있어야 함
- 프로젝트 루트 또는 test 폴더에 샘플 엑셀 파일이 있어야 함

## 검증 항목

### 1. 쿠팡 파서 (coupangParser)
`docs/REF_엑셀_구조.md`의 "1. 쿠팡 주문 엑셀" 섹션 기준:
- 시트명 "Delivery"를 올바르게 찾는가?
- 1행을 헤더로 인식하는가?
- 2행부터 데이터를 읽는가?
- 컬럼 매핑 검증 (★ 표시된 필드들):
  - `주문번호`(idx 2) → orderNo, orderItemNo, matchingKey 모두에 매핑?
  - `등록상품명`(idx 10) → productName?
  - `등록옵션명`(idx 11) → optionName?
  - `구매수(수량)`(idx 22) → quantity (정수 파싱)?
  - 전화번호 원본 보존 + digits 추출?
- rawValues에 40개 셀이 모두 저장되는가?
- 빈 행 스킵이 동작하는가?

### 2. 토스 파서 (tossParser)
`docs/REF_엑셀_구조.md`의 "2. 토스 주문 엑셀" 섹션 기준:
- 1~4행을 정확히 스킵하는가?
- 3행을 헤더로 사용하는가?
- 5행부터 데이터를 읽는가?
- **matchingKey가 `주문상품번호`(idx 2)인가?** (주문번호 아님!)
- 전화번호 하이픈 없는 형식("050877183460")을 올바르게 처리하는가?

### 3. 운송장 파서 (trackingParser)
- A업체: `업체주문번호`(idx 1)를 rawOrderKey로 사용하는가?
- A업체: `택배사`(idx 12), `송장번호`(idx 13) 매핑 정확한가?
- B업체: `거래처주문번호`(idx 3)를 rawOrderKey로 사용하는가?
- B업체: `택배사`(idx 16), `운송장번호`(idx 17) 매핑 정확한가?
- A업체 내부번호("PO20260507..." 컬럼 idx 0)를 무시하는가?

### 4. 플랫폼 자동 감지
- 쿠팡 파일 → "coupang" 반환?
- 토스 파일 → "toss" 반환?
- 잘못된 파일 → 에러 또는 null 반환?

### 5. invalidRow 처리
- 수량이 NaN인 행 → invalidRow에 포함?
- 주문번호 누락 행 → invalidRow에 포함?
- 빈 행 → 스킵 (invalidRow 아님)?

## 엑셀 파서 검증 결과

### 쿠팡 파서

### 토스 파서
✅/❌ 각 항목

### 운송장 파서
✅/❌ 각 항목

### 플랫폼 감지
✅/❌ 각 항목

### invalidRow 처리
✅/❌ 각 항목
